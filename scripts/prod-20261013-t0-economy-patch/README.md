### 3.4 净效果与一个必须说明的风险

以 v4 基线（不含忠诚）+534.44/赛季为底：

| 口径 | 计算 | 结果 |
|---|---|---|
| S9（含 W1 退回一次性） | 534.44 − 591.65 + 57.56 + 10.50 | **≈ +10.85** |
| S10 | 534.44 − 429.30 + 57.56 + 21.00 | **≈ +183.70** |
| S11 | 534.44 − 494.20 + 57.56 + 21.00 | **≈ +118.80** |
| S12 起（忠诚排程归零） | 534.44 + 57.56 + 21.00 | **≈ +612.99（存量 51.7%）** |

⚠️ **T0 只止血、不建 sink**：忠诚这条「隐性抽水」在 S12 到期后会消失，届时仅靠 T0 三项（取消下限 + 维护费软化 + 开 2 档）会把净注入推回 ≈ +613/赛季。这是**设计预期**——结构 sink 与再分配要在 T3b（迁移 0068 转移语义）/T3c（媒体池、entry 池化、团结金、忠诚缴池）/T4（富人税去悬崖、交易税改买方付 + 缴池、设施档位阶梯化）接续；T0 的定位是「开窗前把最不合理的三段先拆掉」。
