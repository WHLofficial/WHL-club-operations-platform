## §0 一页结论

> ⚠️ 本节已按 §9 v4 修正赛制（次级 20 场 / 10 主场、冠军杯 330）重写。旧口径数字（次级 14 场、次级缺口 −249.50、D 77.71、冠军杯 570）只在 §1–§8 里作为推演过程保留。

1. **现状的问题不是「次级奖金低」，而是「收入跟着级别发，不跟着赛事事件发」。**
   四赛事（顶级联赛 / 次级联赛 / 冠军杯 / 超级杯）的钱各自印、各自定价，没有一张统一的赛季印钞预算表：
   现状印钞 Σ **3358.31/赛季**（联赛场奖 2269.20 + 入场 272.50 + 门票 480.61 + 冠军杯 330.00 + 超级杯 6.00）。
   其中 **67.57% 是按场次发的绩效奖金**——这就是「占比不像真实联赛」的根。
2. **重设计的落点 = 同一套赛事事件定价表，级别差由「场次 + 规模 + 媒体池级别切分」承担，不由每场单价歧视承担**（杯赛席位与 16 队赛制由用户 2026-10-13 冻结，不作设计变量）。
   次级每队 20 场（顶级 22 场）、10 主场（顶级 11 个）——场次差距其实很小（−2 场 / −1 主场），
   所以「次级」的真实含义几乎全在**每场单价更低**（6.7/4.8/2.9 vs 8.5/6.6/4.7）与**规模更小**（死忠/容量/档位）上；
   单价歧视是纯粹的双重惩罚，且它换不来任何东西。
3. **同级同价之后，联赛块总额不变**：v4 把「场奖 2269.20 + 入场 272.50 = **2541.70**」整块重切成
   竞技绩效尾 **305.60**（0.80/场）+ 联赛媒体池 **1349.16** + 商业线 **886.94** ⇒ 零注水（2541.70 = 2541.70）。
4. **级别落差 D 的现状是 51.93（每队：顶级 +49.88 / 次级 −2.04）**，v4 q=0.75 落 **51.24**（49.62 / −1.62）——
   即「只换管道、不动相对位置」。**升级动力不能再靠「多打 8 场」**（修正后只多 2 场），
   只能靠三件：**媒体池按级别切分（q）**、**规模上限**（容量/死忠/名次奖金天花板）、**一次性升级奖励 + 降落伞**。
5. **过渡层必须受套利约束 `U + P < D`**：升级奖 15 + 降落伞 12×2 = 39 < 51.24 ✓（q=0.75）；
   若 q 压到 0.70（D=35.48）就必须同时把过渡层压到 35.48 以下。
6. **收入占比必须像真实联赛（§8 → §9）**：现实的主收入是转播（≈50%）与商业（≈30%），都是「年度定额 + 分配键」。
   v4 在总额不变的前提下重排为：媒体 **50.00%**（联赛池 1349.16 + 杯赛 330）、商业 **26.41%**（886.94）、比赛日 **14.31%**（480.61）、竞技尾 **9.10%**（305.60）。
   关键发现：**媒体池必须按级别切分**——q=0.611（按人数平均）会把 D 砸到 **7.43**，等于取消升级动力；q=0.75 才保 51.24。
7. **真正的缺口是忠诚支出，不是「次级」**：按新费率排程，忠诚 S9 **591.65 = 盘子的 17.62%**（S11 稳态 494.20、S12 起 0）。
   次级每队底线随忠诚处理而变：① 销毁（现口径）**−9.45**｜② 缴池均分 **+23.42**｜③ 缴池 K3 **+31.82**。
   系统净注入（不含忠诚）**+534.44/赛季 = 存量 45.03%**；**含忠诚 S9 −57.21、S11 仅 +40.24 ⇒ 基本自平衡**；
   若忠诚改「缴池不销毁」，净注入回到 +534.44，那时必须靠设施五级 / 球场 2–4 档 / 扩建等 sink 把水吸掉。

## §2 四处结构缺陷（赛事角度）

- **D1 次级双重惩罚**：场次少 36%（14 vs 22）**并且**单价低（每场 4.80 vs 6.60）⇒ 次级赛季场奖只有顶级的 **46.28%**。
  少场次是赛制（8 队 vs 12 队），合理；单价歧视不合理——它什么也没换来。
- **D2 冠军杯隐身印钞**（见上）：池 200、入场 240、淘汰赛 130 全是印的，开赛前没有人核算过它；且席位与 16 队赛制已冻结 ⇒ 只剩「金额」一个可调项。
- **D3 入场奖金按级别发**：同一件「打完一个赛季」的事，顶级 20 / 次级 7.5，差 2.67 倍，与场次、成绩、参与全都无关。
- **D4 无升降级过渡**：级别净额落差 **77.71/队/赛季**，降级即断崖（无降落伞、无缓冲），
  而 77.71 这个数本身也是「次级每队每年亏 35.64」的另一面——**落差的一半以上是「次级活不下去」造成的，不是「顶级待遇好」造成的。**

### L2 席位层：**不动**（用户 2026-10-13 冻结：席位与冠军杯 16 队赛制都不改）

- 杯赛**不是设计变量**：平台 20 支俱乐部（18 支非 CPU）里 16 支进杯赛 ⇒ **近乎全员参与**，它既不构成「顶级特权」，也不能用来给次级开偏门。
- 因此杯赛对级别落差的作用是**两级同时抬高印钞**（570/赛季 ≈ 存量的 48%），而不是重分配 ⇒ 唯一可调的是**金额**（`prize_table.champions_group.pool` 与各项单价），不是席位或赛制。
- 单队杯赛收入区间（现行表）：资格赛止步 **7.5** → 小组赛止步约 **15 + 14 + 池分摊 ≈ 40~61** → 夺冠约 **96**。

### L3 过渡层（内部转移，零净额，受套利约束）

- 升级一次性奖励 **U = 15**（当年发放，从版权池预留）
- 降级降落伞 **P = 12/赛季 × 2 赛季**（从版权池预留）
- **硬约束：`U + P < D`**（D = 级别净额落差）。否则「故意降级→拿降落伞→升回来→拿奖金」比留在顶级更划算。
- 附加条件（防摆烂）：降落伞只发给「在顶级待满 ≥2 赛季」的降级队；升级奖只发给「近 2 赛季未降级」的升级队。

### L4 再分配层（内部转移，零净额，条件触发）

团结金（门票超额累进，触发档 ≤0.20→0% / 0.20–0.28→15% / 0.28–0.36→30% / >0.36→45%）、忠诚缴池、富人税回收均分。
**在本设计下这是「备用阀门」而不是「主力水源」**：因为 L0 已经把次级抬到 [−30, 0] 区间内，
再分配层只在收入 Gini 越过阈值时启动（现状门票 Gini 0.3004 ⇒ 自动落 30% 档，池 32.12/赛季）。

### L5 成本侧（用户 2026-10-13 定案：**取消穷鬼线、不降工资帽**）

- **不做**：次级工资帽收紧（58 → 50）已被用户否掉——「不建议降低工资帽」。
- **做**：**取消穷鬼线**（`实扣 = max(Σ现行合同工资, 帽 − 15)` 的抬升项归零）⇒ 全联盟每赛季少扣 **57.56**（顶级 46.80 / 次级 10.76），定量见 §4.6。
- **副作用留给收入侧解决**：阵容规模次级已接近顶级（ΣRC 2510 / 7 = 358.6 vs 4551 / 11 = 413.7），但 v2 之后次级每队收入 109.10 > 帽 58 ⇒ 帽子仍是有效上限、不需要动。
- **前置耦合**：穷鬼线原本有一个「强迫花钱」的副作用（低成本运营队也被扣到 53/43）。取消后廉价阵容队会开始攒钱，而余额税在 ≈119.4 收敛 ⇒ **必须先有足够的 sink 供给**（设施五级阶梯、球场 2–4 档、扩建上限），否则只是把「有钱花不出去」从 4 队扩大到更多队。

## §5 结论：回答「单给次级加奖金，还有什么升级动力」

> 数字口径：本节 1–2 条的金额为 v2 口径；**v3（§8）重排后为：顶级每队 +42.07 → +34.67、次级 −35.64 → −24.01、D = 58.68**（叠加取消穷鬼线后 +38.92 / −22.47 / D 61.39）。
> 结论方向不变：补底来自印钞结构重定价，不来自抽血。

**用户是对的**：单给次级加钱 = 用「同级联赛的收入」去补贴「低级别」，必然压缩落差，也就是花钱买「次级也能过好日子」。
正确做法不是拒绝补底，而是换轨：

1. **补底的钱来自印钞结构的重定价（同级同价），不来自从顶级抽血** ⇒ 顶级绝对额只降 15.11（占其净额 36%），不是被抽走 253。
2. **级别差改由场次（22 vs 14）、上限（容量/死忠/冠名天花板）、落差 D 承担**（杯赛席位与 16 队赛制已冻结，且 20 队里 16 队都进杯赛 ⇒ 杯赛不是升级专属收益）⇒ 升级的收益从「每场单价更高」变成「能打更多场、能把球场和死忠做大、降级时落差有 61.39（v3 含取消穷鬼线）可丢」。
3. **落差必须保留一个下限**：D ≥ 35/队/赛季（v2 设计 38.87、v3 设计 58.68，均达标）；若未来再分配层加码把 D 压到 20 以下，升级将失去经济意义，那时必须同时抬高席位价值或 U。
4. **过渡层受 `U + P < D` 约束**，且降落伞/升级奖都有资格条件，杜绝「降级套利」与「摆烂降级」。

- **中游战绩**：顶级 **+40.33/队**、次级 **+9.50/队** ⇒ **两级别均为正**。次级从「打平（−0.44）」转为正 9.50，来源 = 次级媒体份额提高 5.79/队 + K3 缴池多得 4.20/队 − 顶级媒体让出 3.68/队（顶级由 +46.66 降到 +40.33）。
- **最优者之外的最差者（中游口径）**：慕尼黑1860 **−13.33**、里昂 −4.66、阿森纳 −17.49（阿森纳是唯一中游仍明显为负的次级队，因继承工资 96.74）；次级其余 6 队全部为正（拜仁 **+14.68**、奥林匹亚科斯 +23.34、诺丁汉森林 +60.03、RB莱比锡 −28.85）。
- **最差战绩（全负、form 0.70、无杯赛）+ 现阵容**：**17/18 为负**（1860 −74.67、RB莱比锡 −60.42、阿森纳 −53.33、里昂 −46.30、巴萨 −45.19…；仅曼联 +8.17）——比 q=0.75 版本（14/18）更差，因为顶级媒体池缩小 3.68/队。**这是 q=0.72 的直接代价，必须由降落伞/欠账容忍/窗口自救覆盖。**
- **最差战绩 + 瘦身阵容（19 人 × 1.33/窗 = 50.54/赛季）**：**仅 RB莱比锡 −13.20**，其余 17 队全为正（阿森纳 +4.70、奥林匹亚科斯 +6.44、诺丁汉森林 +16.99 最紧）⇒ 长期可存活成立。
- 结论不变：赤字主因是**继承的工资单**（阿森纳工资×2 = 96.74 vs 最差收入 79.74；RB莱比锡 115.38 vs 61.84），不是结构缺陷；缓冲三件（**降落伞、欠账容忍、窗口内自救**）必须写进制度。

### 10.3 判定 B：战绩收入正向（不变）✓

逐队「每多赢一场」净增量：顶级 **3.79 ~ 4.50**、次级 **3.07 ~ 3.54**，**18/18 队全部为正**。

- 成分：竞技尾 1.60 + 积分层（顶级 2.19 / 次级 1.47，按积分份额）+ 门票 form 效应 0.00 ~ 0.71，团结金按超额累进只削边际 30%，**不改变符号**。
- **无任何反向键**：全部键 = 积分（绝对单调）/上座（绝对规模）/参与资格。
- **弱队弹性更大**：全季战绩摆幅 ÷ 自身收入 = RB莱比锡 **66.22%** vs 曼联 **30.76%** = **2.15×** ⇒ 努力对弱队更值钱。

### 10.4 判定 C：可跨阶层 —— **q、分配键、过渡层三者必须一起定**

D（升级净收益）= **30.8/赛季**（顶级 40.33 − 次级 9.50）。套利闸 = 过渡层（升级奖 U + 降落伞 P）< D。配对表（其余参数不动）：

| q | 缴池分配键 | 次级中游净额 | D | 可行过渡层上限 | 余量 |
|---|---|---|---|---|---|
| 0.75 | 均分 | −0.44 | 47.1 | 39（现状） | 8.1 |
| 0.75 | K3 | +3.76 | **40.2** | 39 | **1.2** |
| 0.74 | K3 | +5.69 | **37.1** | **32**（奖 12 + 保 10×2） | 5.1 |
| **0.72** | **K3（用户定案）** | **+9.50** | **30.8** | **28（奖 12 + 保 8×2）** | **2.8** |
| 0.72 | 均分 | +5.30 | 37.7 | 32 | 4.3 |

- **K3 的代价是 D 被削减 6.88/赛季**（池 295.83 × 0.5/21.5）：次级每队多得 4.20、顶级每队少得 2.67 ⇒ 向上激励只保留 **81.8%**（均分键 100%）。用户已裁决用 K3，故必须用更低的过渡层来守住套利闸。
- 次级内部「垫底收入 → 冠军收入」差 **54.64/赛季**（RB莱比锡 → 拜仁），顶级内部差 82.45（巴萨 → 曼联）。
- **两条不能同时成立**：若要保住现状降落伞（12×2，过渡层 39），D 必须 ≥ 39 ⇒ 只能 q=0.75 + 均分（次级中游 −0.44）；要 q=0.72 + K3（次级 +9.50），过渡层就得压到 **28**。

### 10.5 判定 D：无消极套利 ✓

- 弃权/摆烂单场成本 = 竞技尾 1.60 + 积分层 2.19/1.47 + form 门票损失 ≈ **3.07 ~ 3.79**；杯赛资格与媒体层随名次单调上升 ⇒ 无「缺席更划算」的键。
- 忠诚费率排程的「≥3.5 赛季 0%」不构成囤积激励（尾巴建议改 5%，见 rules 稿 A 类）；尾巴若维持 0%，长期囤积免税仍是缺口。

### 10.6 结论与必须守住的边界

|---|---|---|
