## §0 判决

**现在的制度不是「收入太少」或「差距太大」，而是三条结构性错配。**

1. **流向错**：67.1% 的钱（战绩奖金 2067.60/赛季）按「人人相同」发，而唯一的财政放大器（门票 389.31，Gini 0.3004）按**存量**（死忠×容量×档位）发 ⇒ 努力在财政上不产生回报（赢满整季与全负只差 ±42 顶级 / ±27 次级）。
2. **没有回填**：13 个 sink 全部销毁、账本无对手方；唯一抽强的是**储蓄上限式**富人税（收敛 ≈119.4 就停流，S9 实测 56.16/赛季全落在 PSG）；交易税打在**卖方**（小球队卖人求生被抽）；`match_diff_dest='burn'` 有键无实现。
3. **成本刚性错配**：次级 7 队成本 816.40（工资 728.60 + 维护 87.80）vs 收入 597.60 ⇒ 缺口 **−249.50/赛季 = 全联盟 faucet 的 14.2%**，且降级落差 77.71/赛季、无降落伞。

**革命 = 改流向，不是加钱。** 三件事：① 把 67% 那块均等钱的**载体**从「参赛资格」扩为「参与 + 规模 + 成绩」三层；② 给强队收入加**自动触发上限**（团结金），把超额部分制度化搬给次级；③ 让支出侧与**联盟池**对接（忠诚改支出并**部分**缴池、~~交易税买方付并缴池~~（已冻结）、维护费分级），使「强→弱」成为账面可审计的转移而不是靠参数斜率。

## §3 五条病灶（每条一句话 + 判据）

- **F1 收入按存量分配**：门票 ∝ 死忠×容量×档位，是唯一随赛季单向扩大的收入项（Gini 0.3004，最高/最低 10.69×；四旋钮中**只有死忠是零现金旋钮**）。
- **F2 战绩财政弹性 ≈ 0**：奖金表刻意平（均值 = 人人相同），赢满整季与全负差 ±42（顶级）/±27（次级），占收入 1.4%/3.5% ⇒ 「努力」不产生财政回报，翻身靠的是输入（死忠/容量）不是输出（战绩）。
- **F3 没有回填机制**：13 个 sink 全销毁；抽强的富人税是**余额上限**（125 起征整额 20%，PSG 单窗 28.08、稳定在 ≈119.4）；交易税打在卖方；`match_diff_dest` 只有声明没有消费点。
- **F4 级别错配**：次级成本刚性 816.40 vs 收入 597.60，缺口 −249.50；升降级落差 77.71/赛季、无降落伞 ⇒ 降级即破产。
- **F5 退出无成本**：弃权机会成本仅 6.6/4.8（薪资下限的 8.87%/6.74%）；同时穷鬼线反向再分配（每赛季从 3 支最穷队多收 57.56）。

## §4 革命纲领（四件套）

**R-A 收入三层化**（载体重组，不新增货币）

| 层 | 内容 | 分配键 | 摆烂安全性 |
| --- | --- | --- | --- |
| 保底层 | entry 池化（272.50 均分 15.14/队）+ 忠诚缴池再分配 + 媒体池均分层 | 参与资格（参赛即得） | 缺席即失格，安全 |
| 规模层 | 门票 / 商业 / 冠名 / broadcast —— 自留，但受**自动上限**约束 | 绝对规模（票房/上座） | 放水即自伤基数，安全 |
| 成绩层 | 战绩奖金（保留均等）+ 媒体池积分层（25%）+ 绝对积分键加成 | 绝对单调量（积分） | 单调 ⇒ 无「放一场更划算」的反差点 |

**R-B 自动触发上限（团结金）**：门槛 = 门票中位数（本季 19.15），超额部分按**门票 Gini 自动选档**抽成入池：Gini ≤0.20 → 0%；0.20–0.28 → 15%；0.28–0.36 → **30%（现状 0.3004 自动落此档）**；>0.36 → 45%。池按 K3 权重复分（顶级 ×1、次级 ×1.5）。**距阈值越远抽得越狠，收敛后自动归零**——规则化、可预期、不需人工调参。

**R-C 成本侧对齐**：次级维护费减半（−43.90）、工资下限符号反转（+10.76）、忠诚由 faucet 改 sink（S9 −591.65，改的是方向与量级口径）。

**R-D 转移语义（架构）**：`ledger_entries` 目前是单边流水（一方扣/入、无对手方）。要支持「转移」必须新增**对手方 / 转账组 / 联盟账户**语义，并保证净额为零、可回滚、被订正批批量重算覆盖 ⇒ **需要 0068 级迁移 + 一份 ADR**（`memory/design-s9-solidarity-fund.md` §6 已起草）。

## §8 反摆烂与反投机审计

- **名次键弃用（定量结论）**：名次单价 = P/28。池 106.40（缺口的 43%）时放 1 场恰好打平，放 2 场 −3.80 ⇒ 这是**不招摆烂的上限**；要覆盖缺口（249.50 ⇒ 单价 8.91）则放 1 场 +5.11、放 2 场 +1.31 **均为正** ⇒ 名次键没有「既有效又安全」的工作点。另有三个结构性缺陷：进步税（补贴按名次当季消失而门票/死忠滞后）、名次是队伍自己能改的输出、季末局部摆烂惩罚面最小（NBA 型）。
- **本次方案允许的键**：① 绝对单调量（积分/上座/票房/ΣRC）—— 即使按份数分池也只产生稀释，不产生反转；② 参与键（entry 均分层）—— 缺席即失格；③ 规模键（门票/商业/冠名自留）—— 放水直接降自己的分成基数。**全制度不出现任何名次键**。
- **投机面**：团结金按**门票**抽成 ⇒ 无「少报上座」动机（少报即少收）；交易税若改买方付 + 缴池，需防「关联队对倒」（用 `transfer_tax` 现成审计 + 换手率告警）。

## §9 通胀与 sink 平衡

- **注入**：全联盟净额 +213.26/赛季 = 存量 17.97%（偏高但可控）；存量 1186.73 只等于 **0.58 个赛季的工资口**（2045.36）⇒ 货币存量薄，一次大额事件（半程窗建设 108）就能改变格局。
- **半程窗**：18 队全做「广播 L1 + 商业 L1 + 冠名稳健」时 faucet +70.10 vs 建设流出 108.00 ⇒ 净 **−37.90**（存量 3.19%，本赛季节点上的首次「sink > faucet」）。
- **sink 质量**：广播 L1（3.0M）人人同回报（年化 3.30/2.10，回本 0.9/1.4 赛季）——**这是唯一均等的 faucet 增强器**；商业 L1 回本 1.4（PSG）→ 14.2 赛季（RBL）；五级有效成本 37M。**四队已顶到 35000 座位上限、有钱花不出**（PSG 140.42 / 利物浦 122.84 / 尤文 110.59 / 拜仁 53.90）⇒ 需要的不是更多 sink 而是**阶梯化的 sink**（设施五级 + 档位 2–4 档 + 常设活动/青训）。
- **S12 风险**：忠诚归零后 sink 少一块（S11 −494.20 → S12 0），若不补常设 sink，净注入回升到 +213.26 以上。
- **sink 设计原则（本次评估立场）**：把「有钱花不出」变成「有值得的目标」——设施/档位阶梯写进迁移（L6），而不是靠罚金式 sink；富人税去悬崖（改成对**超阈值增量**的平滑税率），让它像目标而不是税。
