## 0. 一页结论

1. **吸引力：够，但别用「8 倍」那种说法。** 杯赛小组赛每场名义奖金 **3.50**（池 168 / 16 队 / 3 场），是竞技尾（0.80/场）的 4.4 倍；淘汰赛赢一轮 **14 / 18 / 10 = 竞技尾的 17.5 / 22.5 / 12.5 倍**。但联赛单场不是只有竞技尾（见 §7.3）：相对联赛每场总收入（顶级 8.80 / 次级 5.96），杯赛小组单场只有 **0.40× / 0.59×**，按实力加权后最强队 0.72×/1.06×、最弱队 0.11×/0.17×。杯赛真正的价值是**向上抽奖券**（冠军 65.11 = 顶级联赛收入 33.6%、次级 54.6%），而不是「每场更值钱」。对次级队，杯赛占其联赛收入 **13.7%~16.4%**（顶级 9.3%~10.4%）。
2. **落差：资格赛本身几乎不值钱，真正的落差在「进没进正赛」和「走多远」。** 止步资格赛 7.50 → 正赛小组出局 10.21（只差 2.71），但 → 8 强 19.53、→ 4 强 35.32、→ 亚军 55.11、→ **冠军 65.11**。整条阶梯 65.11 = 次级全季联赛收入的 **54.6%**、= 升降级落差 D(51.24) 的 **1.27 倍**。
3. **贫富差距：跨级别拉平、级别内拉大，净效应≈0。** 杯赛收入 Gini **0.42**（S9 全员参赛实测）——比现金 0.3173、门票 0.2407 都高，是全系统最集中的一条 faucet；但它对次级更重 ⇒ 纯联赛收入 Gini 0.14 → 加杯赛奖金后仍 **0.14**。**新增的不平等点是「资格」本身**：16 队制下 4 支非 CPU 队零收入，把 4 个零放进分布 Gini 直接升到 **0.52**。
4. **三个口径缺陷使其目前一分也发不出来**：S9 淘汰赛 14 场全部 pending，若不在开打前修，**S9 淘汰赛晋级奖金 = 0**（不是发错，是零发放）。
5. 建议：先修三处口径缺陷（按轮次显式定价，`2**(round-1)`，两回合按对阵结算），池 168 + **单价 B 方案 14/18/10**（杯赛奖金合计 270 = 盘子 8.19%，零注水）；资格赛保底 7.5 → **15**（让「差一步进正赛」有实际分量）。
6. **按实力加权的期望值口径（§5.4，回应 m03275）：杯赛不是拉平机制。** 参赛条件期望 Gini 0.362（最强 50.92 : 最弱 3.44 = 14.8×），**加上「弱队常常进不去」后无条件期望 Gini = 0.497**（RBL 0.11、贝蒂斯 0.00、奥林匹亚科斯 1.22 vs 皇马 51.01）。且**级别 ≈ 实力并不成立**（跨级级别桥 M = 1.018，样本薄弱但方向一致）：次级里坐着强度序第 1/3/13 的队，顶级里有倒数第 1。⇒ 缩小贫富差距只能靠**保证层**（媒体池均分、商业均分）与成本侧，不能靠杯赛。

## 2. 池语义（先把钱的来路算清）

`prize_table.champions_group.pool`（现 200）**已含逐场奖**：结算时 `remaining = pool − Σ(胜×7 + 平×2.5)`，余量按胜场占比分给有胜场的队（`src/worker/season-settle.ts:143-157`）。

- 16 队制小组赛 = 4 组 × 4 × 单循环 = **24 场**；按 S9 实测 20% 平局 ⇒ 19 个胜场、5 场平局。
- 已发 = 7×19 + 2.5×5×2 = **158.00** ⇒ 余量 10.00 ⇒ 每胜加 0.53 ⇒ **每胜有效值 7.53**（名义 7.0）。
- 池 168 ⇒ 小组赛总支出 **168**；淘汰赛（B 方案）4×14 + 2×18 + 10 = **102**；合计 **270**。
- `champions_group.entry`（15）在整个 `src/` 零消费点 ⇒ **入场奖从未实现**，本模型不含它（建议保持不实现，否则 16×15 = 240 直接把杯赛从 270 抬到 510）。

## 3. 问题一：是否吸引人参赛

### 3.1 每场口径

| 口径 | 顶级 | 次级 |
|---|---|---|
| 联赛每场总收入 | 8.80 | 5.96 |
| 联赛每场竞技尾 | 0.80 | 0.80 |
| 杯赛小组赛每场奖金期望 | 6.52（= 0.74× 顶级每场 / 1.09× 次级每场） | |
| 杯赛每场 / 联赛竞技尾 | **8.15×** | **8.15×** |
| 淘汰赛一轮（14 / 18 / 10） | = 17.5 / 22.5 / 12.5 × 联赛竞技尾 | 同左 |

### 3.2 赛季口径（占联赛收入）

| | 杯赛（2 胜小组出局） | 占联赛收入 |
|---|---|---|
| 顶级（11 队） | 17.74 ~ 20.90 | 9.29% ~ 10.43% |
| 次级（7 队） | 15.91 ~ 18.53 | **13.71% ~ 16.36%** |

### 3.3 参赛有没有隐性成本

- 唯一边际成本是**维护费的 per_10k 项**（按主场场次计）：顶级 22000 座 tier1 = 1.21/场、12000 座 tier0 = 0.96/场。
- 主场净额（门票 − 维护/场）：最高 **+2.06（曼联）**、最低 **−0.39（RB莱比锡：单场票 0.57 < 维护 0.96）** ⇒ 只有最低上座队的主场是负毛利，靠奖金覆盖。
- 无伤病/疲劳机制 ⇒ 多打比赛没有机制成本；反而有隐性收益：杯赛主场计入 `match_attendance` ⇒ 参与**死忠（fans）的逐场演化**（`src/worker/home.ts:590-597, 627-629`），死忠是审计 §3.7 里唯一的**零现金成长旋钮**。

**判定：吸引力成立。** 杯赛是「高倍率、低门槛、无机制成本」的钱，弱队相对收益更大。

## 4. 问题二：落差（未获资格 / 止步资格赛）

| 情形 | 小组奖金 | 淘汰奖金 | 杯赛门票 | 杯赛合计 | 占顶级联赛收入 | 占次级联赛收入 |
|---|---|---|---|---|---|---|
| 未获资格（16 队制外 4 队） | 0 | 0 | 0 | **0.00** | 0% | 0% |
| 止步资格赛 | 7.50 | 0 | 0 | **7.50** | 3.88% | 6.29% |
| 正赛小组出局（1 胜） | 7.53 | 0 | 2.69 | **10.21** | 5.28% | 8.57% |
| 正赛小组出局（3 胜未出线） | 22.58 | 0 | 2.69 | **25.26** | 13.05% | 21.20% |
| 8 强（QF 两回合负） | 15.05 | 0 | 4.47 | **19.53** | 10.09% | 16.38% |
| 4 强（SF 负） | 15.05 | 14.00 | 6.27 | **35.32** | 18.25% | 29.63% |
| 亚军 | 15.05 | 32.00 | 8.06 | **55.11** | 28.47% | 46.23% |
| 冠军 | 15.05 | 42.00 | 8.06 | **65.11** | 33.64% | **54.62%** |

（门票按中位队单场票 1.79 计；实际按队，顶级可达 3.90/场）

> ⚠️ 本表是**全军名义阶梯**（假设每队都走到该档）。按各队真实胜率加权的期望值见 §5.4：最弱队（拜仁/阿森纳）即使参赛，期望也只有 2.3~3.4。

### 落差阶梯

- 未获资格 → 止步资格赛：**+7.50**
- 止步资格赛 → 正赛小组出局：**+2.71** ← **资格赛几乎白打**
- 小组出局 → 8 强：**+9.32**
- 8 强 → 4 强：**+15.79**
- 4 强 → 亚军：**+19.79**
- 亚军 → 冠军：**+10.00**
- 整条：**+65.11 = 次级联赛收入 54.6% = D(51.24) 的 1.27 倍**

### 关键判定

1. **资格赛保底 7.5 与「正赛小组出局」只差 2.71** ⇒ 资格赛的货币落差形同虚设，真正的作用是「拿到 4 倍上限的抽奖券」。6 队争 2 席 ⇒ 每队 1/3 概率进入正赛（正赛期望 ≈ 20，上限 65）。
2. **整条杯赛阶梯（65.11）大于整个升降级落差（51.24）**。这不构成摆烂激励（杯赛晋级与取胜完全单调），但意味着**一个次级队单季的杯赛上限收益超过「升上顶级」的一次性收益**：升上去是每季 +43.81 媒体池（永久），杯赛冠军是一次性 65.11。两种激励并存时，赛季末的边际意义会从「争升级」偏移到「争杯赛」——建议**杯赛阶梯不得超过 D**（即冠军奖金总额 ≤ 51.24 − 门票部分）。
3. **资格门槛是新增的不平等点**：16 队制 = 14 支非 CPU + 2 支 CPU ⇒ **4 支非 CPU 队整季零杯赛收入**，而杯赛对次级是 14~16% 的收入。

## 5. 问题三：对贫富差距的作用

### 5.1 Gini 实测与模型

| 口径 | Gini | 最高/最低 |
|---|---|---|
| 杯赛收入（S9 实测，20 队全员参赛） | **0.4172** | 27.21（PSG） / 0.00（巴萨、RBL） |
| 杯赛收入（16 队制模型，14 参赛 + 4 零） | **0.52** | — |
| 杯赛收入（16 队制模型，仅 14 参赛队） | 0.38 | — |
| 杯赛收入（假设人人小组出局、无 KO 分化） | 0.04 | — |
| 现金（2026-10-13） | 0.3173 | 140.42 / 2.16 |
| 门票（修正后） | 0.2407 | 7.43× |
| S9 全部 faucet | 0.1801 | — |
| S10 联赛收入（模型，不含杯赛） | 0.14 | — |
| S10 联赛收入 + 杯赛奖金 | **0.14** | — |

### 5.2 两条相反的力

1. **跨级别：进步（拉平）。** 杯赛是唯一**不看级别**的奖金：次级与顶级同单价。相对收入贡献次级 13.7~16.4% > 顶级 9.3~10.4% ⇒ 杯赛天然偏向小球会。
2. **级别内：集中（拉大）。** 钱按胜负发，冠军拿 65.11、小组全败只有 0 ⇒ 杯赛 Gini 0.42 高于现金 Gini 0.3173。

两力相抵 ⇒ **把杯赛加进总收入，Gini 从 0.14 到 0.14（几乎不动）**。它是「不改变横向差距、但抬高整体波动」的科目。

> ⚠️ 以上是**名义值口径**（假设每队都能走到那一档）。按**实力加权**后结论不同：见 §5.4 —— 净效应不是 0，而是显著集中（无条件期望 Gini 0.497）。

### 5.3 唯一的结构性风险

- **资格门槛**把 4 支弱队排除在外（Gini 0.42 → 0.52）。
- **杯赛上限超过升级落差**（65.11 > 51.24），激励主次可能倒置（见 §4 判定 2）。
- **CPU 队是纯对手不给钱**（`src/worker/prizes.ts` 发钱闸）⇒ 8 强含 AC米兰时 S9 实发低于满额；若未来 CPU 占比上升，杯赛奖金会「漏发」（预算花不出去）。

### 5.4 期望值口径：按实力加权后（回应 m03275「弱队赢得概率更小」）

§4 的阶梯表是**全军名义值**（假设每队都能走到那一档）。真实情形是「每档要赢才到得了」，所以必须按**每队的胜率加权**。模型 `scratch/cup-ev.mjs` → `scratch/cup-ev.out.txt`。

**第一步：先把实力估出来。** 两级各自拟合 Poisson 攻防（顶级 59 场 / 次级 34 场，主场优势共享 **1.182×**），跨级对局做级别桥。

| 关键量 | 值 | 说明 |
|---|---|---|
| 级别桥 M | **1.018**（±1σ 约 0.82~1.26） | 跨级 18 场：顶级队进球 31 / 期望 26.66；次级 19 / 期望 16.94 ⇒ **与「两级别实力相当」在噪声内不可区分** |
| 强度序前 4 | 皇马 1.52 / 曼联 1.02 / 诺丁汉 1.00 / 佛罗伦萨 0.83 | 与实测场均积分一致（皇马 2.50、曼联 2.22、诺丁汉 2.00、佛罗伦萨 2.63） |
| 强度序后 4 | 阿森纳 −0.78 / 拜仁 −0.86 / RBL −1.48 / 贝蒂斯 −2.70 | 贝蒂斯 8 场 0 分、场均净胜 −2.38 |

**★ 关键发现 1：级别与实力不对应。** 次级里坐着强度序第 1（皇马）、第 3（诺丁汉）、第 13（维拉）；顶级里有第 20（贝蒂斯）。所以「杯赛不看级别 ⇒ 对弱队友好」这句要打折：**杯赛确实不看级别，但次级里最强的队比顶级一半以上的队都强**（M≈1.0 意味着两个级别的实力分布是完全重叠的）。

**第二步：参赛条件期望（16 队 = 资格概率前 14 非 CPU + 2 CPU；4 组单循环 + 8/4/决赛两回合；池 168 + 14/18/10）。**

| 口径 | Gini | 最高 : 最低 |

| 含门票（14 非 CPU 队） | **0.362** | 50.92（皇马）/ 3.44（拜仁）= **14.82×** |
| 仅奖金 | 0.357 | — |
| **仅小组赛那一段** | **0.223** | 6.30/场（皇马）: 0.99/场（拜仁） |

前 4 强平均 **42.38**/队 vs 后 4 弱 **4.21**/队 = **10.06×**。P(夺冠)：皇马 **46.3%**、曼联 17.8%、诺丁汉 13.9%、佛罗伦萨 10.7%，其余全部 <5%（拜仁/阿森纳 0.0%）。

**结论（回答 m03275）：按期望值口径，杯赛不是拉平机制，而是一条「按实力单调发放」的集中通道。** 它「跨级别拉平」的旧结论建立在「级别 = 实力」这个前提上，而本季数据里该前提不成立（M≈1.0）。要缩小贫富差距，不能靠杯赛（它给最能赢的队发最多），只能靠**保证层**（媒体池均分层、商业均分）与**成本侧**。

**级别桥敏感性**（跨级样本仅 18 场，必须给带宽）：M=1.00 ⇒ 顶级/次级每队期望 22.29/20.63、最强:最弱 16.4×；M=1.02 ⇒ 22.47/20.33、17.2×；M=1.20 ⇒ 24.49/17.02、22.2×；M=1.40 ⇒ 26.08/14.32、31.2×。⇒ M 越大「级别的钱」越集中，但**级别内 16× 以上的差距在任何 M 下都存在**（差距的主因是队与队的实力差，不是级别）。

## 6. 三个口径缺陷（当前一分也发不出来）

`koProgressPrize`（`src/worker/prizes.ts:115-125`）：`after = stageEntryCount / 2 ** round`，after=8→quarterfinal / 4→semifinal / 2→final / 1→champion。

| # | 缺陷 | 后果 | 修法 |
|---|---|---|---|
| 1 | 赛事库 stage 7 的 `config_json` = `{"legs":2,"third_place":false,"source":{…}}`，无 `entry_count`/`bracket_size`/`size` ⇒ `stageEntryCount()` 返回 null（`src/worker/results.ts:494-507`） | `koProgressPrize` 首行 return null ⇒ **S9 淘汰赛 14 场零发放**（非发错） | 在赛事库 stage config 补 `bracket_size: 8`（不改平台代码，但会触发缺陷 2/3） |
| 2 | round 从 1 起算 vs 算式隐含 0 起算 | round1 ⇒ before=4 ⇒ 误按**决赛档**发；round3 ⇒ before=1 ⇒ **决赛反而不发** | 改成显式按轮次：`2 ** (round - 1)` 或直接按「本阶段首轮/次轮/末轮」定价 |

### 7.3 联赛对照基准的正确口径（回应 m03275「不能只按显式的 0/0.8/1.6 对比」）

杯赛的钱要跟「联赛的钱」比，而联赛的钱不是竞技尾那 0.80/场——它是三层叠加：

| 层 | 金额/赛季 | 性质 |
|---|---|---|
| **保证层**：媒体池均分层 50% | 1349.16 × 50% = **674.58** ⇒ 顶级 **45.99**/队、次级 **24.09**/队 | 与赛果**无关**（出场即有） |
| **保证层**：商业线 40% 均分 | 886.94 × 40% = 354.78 ⇒ **19.71**/队（另 60% 按规模加权） | 与赛果**无关** |
| **结果层**：竞技尾 | **0.80/场**（胜 1.6 / 平 0.8 / 负 0；每场双方合计恒 1.6） | 逐场随赛果 |
| **结果层**：媒体池积分层 25% | **337.29**（每名次约 2.30 顶级 / 2.23 次级） | 赛季末按名次 |

- 联赛「胜 vs 负」的边际价值 ≈ 竞技尾 1.6 + 积分层 1.9（3 分 × ~0.63/分）≈ **3.5/场**；「平 vs 负」≈ 1.0/场。
- 这个边际相对「顶级保证层（45.99 + 19.71 ≈ 65.7）」只有约 **5%** ⇒ **联赛内部，单场胜负对收入几乎无影响**（这是 v4 设计的本意：把波动交给杯赛与名次层，保证层守住生存线）。
- 所以「杯赛每场 = 联赛竞技尾的 8.15 倍」的正确解读是：**8.15× 是相对「竞技尾」这一层的倍数，不是相对联赛每场总收入的倍数**。相对联赛每场总收入：杯赛小组单场期望（名义 3.50/场）÷ 联赛每场（顶级 8.80 / 次级 5.96）= **0.40× / 0.59×**；按实力加权后最强队 6.30/场 ⇒ 0.72×/1.06×，最弱队 0.99/场 ⇒ 0.11×/0.17×。
- ⇒ 正确的吸引力表述：**对中上游队，杯赛单场约等于联赛单场；对下游队，杯赛单场远低于联赛单场（但它没有下行风险：输了不影响联赛收入）**。杯赛的真实价值不在「每场更值钱」，而在「赢到底能多拿 65.11 = 顶级联赛收入的 33.6%」，是一张**向上抽奖券**。
