# 中国球员计划 · 创造层设计（国脚复兴体系）

> 2026-11-10 · 状态：**设计稿，待用户圈定分期，未开工**
> 定位：基线版（`2026-11-10-china-plan-rework-design.md`，PA 83 / 提速 / 孵化器）管「强度够不够」；本层管「灵魂」——让中国球员成为联赛的叙事引擎，而外国球员永远不会有的机制载体。
> 用户指令：基线「没有超出原有规则框架，不够有创造性」→ 本层全部为破框设计；逐条标注破的是什么。

## 0. 总纲：一条主线串六件套

主线 = **「国脚复兴」**：教练练的是自家球员，但所有俱乐部的选择汇成一条全服进度线（中国足球水平），进度线反过来改变全服的规则参数与新血供给。个人轴（①）给身份与钱，策略轴（②③）给决策深度，全服轴（④⑤）给共同叙事，⑥是烟火。

破框总览：

| # | 机制 | 破的框架 |
|---|---|---|
| ① 国脚生涯轴 + 武磊效应 | 球员有第二条跨队携带的成长轴；PA 有制度性破口 | 「成长只属于俱乐部」「PA 是绝对天花板」 |
| ② 归化导师制 | 外援的价值包含「带娃能力」 | 「球员强度 = 自身属性」 |
| ③ 留洋外租 | 用不可用换更强成长 | 「我的球员要么在队要么卖掉」 |
| ④ 复兴进度条 | 零和联赛里的合作博弈 | 「你练的球员只对你有用」 |
| ~~⑤ 黄金一代~~ | ~~平台生成球员~~ | **已裁撤（2026-11-10 用户裁定：不自造人、不选秀）** |
| ⑥ 中国德比 | 焦点战加成 | 纯增量 |
| ⑦ 归化（可选） | 「中国人」可以是一种俱乐部决策 | 「国籍是只读属性」 |
| ⑧ 国产赞助专场（可选） | 练中国球员打开赞助柜 | 赞助与阵容脱钩 |

## 1. ① 国脚生涯轴 + 武磊效应（身份 × 商业，推荐做芯子）

### 1.1 数据

新表 `national_career (player_id PK REFERENCES players, points REAL NOT NULL DEFAULT 0, tier INTEGER NOT NULL DEFAULT 0, caps INTEGER, goals INTEGER, assists INTEGER, first_reached TEXT, updated_at)`。跨队携带：行属球员，转会/解约不清（国家队身份是他自己的——与基线「china 徽章离队失效」刻意相反）。

### 1.2 资历点（caps points）

只认已确认赛果的出场（`growth_events('appearance')`，录入/OCR 既有链路），季末结算统一计：

| 来源 | 点数 |
|---|---|
| 每次出场 | +2 |
| 单场评分 ≥8 | +1 |
| CA 里程碑（一次性） | 75→+10，80→+15，83→+20 |
| 留洋成功（③） | +15 |
| 中国德比（⑥）胜方出场 | +1 |

### 1.3 档位（thresholds 按主力约 20 场/季校准）

| tier | 名号 | 门槛 | 待遇 |
|---|---|---|---|
| 1 | 国青 | 20 | 角标 |
| 2 | 国家队边缘 | 50 | 球衣收入解锁（小额） |
| 3 | 国脚 | 100 | 影响力系数 +10%；首发上座需求 +2%；球衣收入全额 |
| 4 | 主力国脚 | 180 | **破格 PA +1**（83→84） |
| 5 | 核心国脚 | 280 | **破格再 +1**（累计 85）；冠名报价 heat +0.1；全服播报 |

节奏：全职主力第 1 季末 T2、第 2 季 T3、第 3 季 T4、第 4 季 T5——19 岁签入的 60 CA 苗子，23 岁时 83~85 + 核心国脚，正是「练成当家球星」的完整弧线。破格上限 +2，全服极少数人能到 85。

**「全村的希望」**：每个 tier 的全服第一名，永久金标进荣誉记录（`national_career.first_reached` + meta 表），冠名 heat +0.05。先发者得，制造抢跑叙事。

### 1.4 武磊效应（球衣与代言收入）

季末结算，对每名在册中国球员：`merch = config 基线 × tier 系数 × 表现系数`。草案：T2 0.3m、T3 0.8m、T4 1.5m、T5 2.5m/季（表现系数 = 当季评分均值/7，钳 0.8–1.3）。**量级压在冠名之下**（冠名才是大钱，球衣是零花+荣誉感）。平衡阀门：
- 每队每季 merch 合计钳 ≤ 6m（config）。
- 反噬：merch ≥1m 的球员续约期望工资 +10%（「球星要分成」），自我平衡。
- 新 faucet 有 sink 对冲：破格 PA 的存在本身就抬高长期工资与续约风险。

## 2. ② 归化导师制（阵容策略层）

### 2.1 数据

`mentor_links (id, club_id, mentee_id UNIQUE, mentor_id, bond REAL DEFAULT 0, created_at, broken_at DEFAULT NULL)`。

### 2.2 规则

- **导师资格**：外援（非中国计划）、CA ≥ 徒弟 CA + 8、同位置组（热区相邻即可）、当季为本队出场 ≥ 5；一名导师最多带 2 徒弟。
- **绑定**：教练在球员页操作；换绑 bond 清零（防滑动优化）。
- **深化**（赛果确认时，数据链路已验：TOUR_DB `tactic_submission.slots_json` 首发）：师徒同场首发 bond +0.5，仅徒弟首发 +0.2，钳 10。
- **效果**：季末该徒弟 XP ×(1 + 0.05 × bond)（最高 +50%）。
- **断裂**：导师转会/解约/外租自动断，bond 作废；徒弟转会导师关系随队清。

### 2.3 为什么它改变决策

签外援从「买即战力」变成「买即战力 + 买教官」：一个 CA 84、声望 4、位置组匹配的老将，对重建队价值高于 CA 86 的错位球星。首发编排多一层「把娃放导师旁边」的解。数值上：一线主力 + 导师满羁绊 = 68 XP × 1.5 = 102 XP（10 级 × 3CA = +30/季）——**一线带导师比训练营快**，这是有意的：真实比赛 > 训练，但代价是他要占一线名额、拿一线工资、在场上可能被虐。营=安全慢，一线带导师=快但贵，③留洋=最快但失控。三条路各有机理。

## 3. ③ 留洋外租（时间换强度）

### 3.1 数据

`china_loans (id, player_id UNIQUE ACTIVE, from_club_id, cpu_club_id, season, status ('active','returned','settled'), outcome_json, created_at)`。

### 3.2 规则

- 目的地限 4 支 CPU 队，每队同时 ≤2 人；期 = 整个赛季，**不可召回**；期间不占本队任何名额、无工资；球员在对方阵容可见（CPU 队名单）。
- 每名球员生涯 ≤2 次。
- **季末结算**（`seededUnit` 钉 loan id，确定性伪随机）：75% 成功 = CA 直升 20–26（钳 PA 83）+ 国脚点 +15 + 全服播报「留洋归来」；25% 失败 = 仅 +6–10，其中 1/3 触发「状态低迷」事件（下季前 3 场 XP 减半，复用事件域播报，不发明伤停系统）。
- 期望速率 ≈ 营 × 1.1~1.3，但方差大、且那一季他不能为你出场——「送出去练一年，回来直接主力」的规划豪赌。

## 4. ④ 复兴进度条（全服层）

### 4.1 数据

`server_progress (id=1, level INTEGER, points REAL, season_points_json, history_json)`；季末结算推进。

### 4.2 计分

`当季 server points = Σ(在册中国球员出场 ×1 + 评分≥8 ×2)`——只认确认赛果。全服 ~20 轮 × 若干首发中国球员，量级实现时按真实轮数校准档位。

### 4.3 档位与全服奖励（每级在季末结算时锁定，只升不降）

| level | 解锁 |
|---|---|
| 2 | 转播分成：每队每季 +0.5m（活动收入新 kind `broadcast`） |
| 3 | 品牌池进 1 家「国产头部」品牌（naming 联动，行业运动/科技） |
| 4 | 转播涨到 +0.75m/队；中国德比收入加成 ×1.2 |
| 5 | 转播 +1m/队；「复兴」全服事件 + 荣誉墙（历届水平线永久展示） |

奖励全部走既有机制消费（账本新 kind、品牌池、事件域），无新生成端。

### ~~4.5 黄金一代生成~~（已裁撤）

2026-11-10 用户裁定：**不自造球员、不做选秀**。原「每季生成 2 名 18 岁新中国人 + 倒序选秀」与配套的 fc_id 900001+ 自编段、换版导入豁免验证一并作废；新血供给维持「EA 换版数据自然带来」。

## 5. ⑥ 中国德比（烟火，顺手）

赛果确认时：双方首发各有 ≥1 名中国计划球员 → 该场标记「中国德比」：比赛日收入 ×1.15（双方）、当日中国球员 XP ×2、QQ/站内全服播报。已知缺陷照抄 D1 的：未提交阵容沿用上一场（沿用就沿用，德比判定同源即可）。

## 6. 可选扩展（⑦ 归化 / ⑧ 国产赞助专场）

- **⑦ 归化**：外援入队满 3 季、年龄 ≥24、一次性 12m → 获中国计划待遇（徽章名额、国脚轴、⑥ 计数），tier c3 不加（国籍档位不真）。每队同时 ≤1 人。艾克森剧本。牵动大（与 ①④ 交互），独立拍板。
- **⑧ 国产赞助专场**：品牌池加 `domestic` 标签，门槛「阵中国脚 ≥1 或中国球员 ≥2」才能签，报价 heat +0.1。练中国球员 = 打开赞助柜。依赖 naming C 块节奏，挂账后排期。

## 7. 分期建议

| 期 | 内容 | 一句话 |
|---|---|---|
| A（灵魂） | ①国脚轴 + 球衣收入 + ⑥德比 + 全服播报 | 身份与生意，上线即「中国球员有故事」 |
| B（深度） | ②导师 + ③留洋 | 重度玩家的阵容与规划解 |
| C（全服） | ④进度条（奖励全走既有机制） | 合作叙事；无自造人、无选秀 |
| D（可选） | ⑦归化 + ⑧国产赞助 | 联动扩展，另拍板 |

依赖：A/B/C 都叠在基线版之上（PA 83 / 速度 / 孵化器先行或同批）。每期独立可上线、可回滚（config 闸门 + 表隔离）。

## 8. 防滥用与平衡清单

- 球衣收入每队钳 6m/季 + tier 封顶；merch 反噬续约工资 +10%。
- 导师换绑清零；导师需真实同场首发（tactic_submission 可验证）；一徒一师、一师两徒。
- 留洋每队同时 1 人在外、每人 ≤2 次、不可召回。
- server points 只认确认赛果；档位只升不降（防摆烂操纵）。
- 破格 PA 全服 +2 封顶且需要 3~4 季全职主力才能摸到。
- 全部数值进 config（复用注册表模式），上线后可不动代码调平衡。

## 9. 与既有系统的接口

- 出场/评分：`growth_events`（录入/OCR 链路，确认赛后可用）——①④⑥ 的数据底座。
- 首发：TOUR_DB `tactic_submission.slots_json`（`player-matches.ts` 既有读法）——②③⑥ 用。
- 收入：账本 `ledger_entries` 新 kind（`merch` / `broadcast`），挂关窗批或赛果钩子，幂等 ref 锚（`('merch', window, refId)` 既有闸模式）。
- 播报：`notify.ts` 模板 + AstrBot QQ 白名单（跨仓确认项，与 window_signals 同批待办）。
- 事件域：③ 失败「状态低迷」、④ level5「复兴」复用 event 播报形态。
