> 版本号待定（owner 另有会话可能占号，以最终 `package.json` 为准；本文档先按 6.69.0 记录）。
> 范围：`docs`/`memory` 之外的 5 个交付面 —— 图标资产、描述数据、徽章展示（桌面 title / 窄屏弹层）、
> `/playstyles` 图鉴页与 ≡ 菜单入口、商店徽章卡行内说明、`/assets/icons/*` 的 404 语义。

## 1. 输入与现状

| 事实 | 证据 |
|---|---|
| 图标此前从未上线 | `web/public/assets/icons/playstyles/` 不存在；生产该路径命中 SPA 回落（`200 text/html`），`onError` 把 `<img>` 隐藏 |
| 图标来源 | GitHub `canicccv/FC26-Playstyles`（basetrait 白剪影 / icontrait 金菱形），经 jsDelivr 取 72 枚 PNG |
| 描述来源 | FUTBIN `26/playstyles` 整页（UIA 读窗取得），36 条 `Info / Playstyle / Playstyle+`；FC26 与 FC27 页逐字段一致 |
| 文案口径 | 中文重写，非逐字翻译；`+` 不是线性增强，金档单独成句 |
| 缓存边界 | `web/public/_headers` 对 `/assets/*` 设 `max-age=31536000, immutable` ⇒ 将来换图必须换路径段 |
| 命中判定 | `wrangler.jsonc` 的 `run_worker_first` 增加 `/assets/icons/*`，Worker 只把 `text/html` 回落改判 404 |

## 4. 验收

- `npm run typecheck`（三份 tsconfig）全清。

- 全量：`npm test` 全绿（基线以 v6.68.2 实测为准，新增用例数 ≥ 20）。
- `npm run build` 通过（仅既有 >500 kB chunk 警告）。
- 变异 M1–M7 逐条变红并回退；M8 留部署回读。
- 版权/署名：图标镜像无 LICENSE ⇒ ROADMAP 写明来源与「仅作玩法说明」；描述为中文重写，不逐字复制 FUTBIN。

## 5. 已知边界

- 图标为第三方镜像，EA 若改版式需换源并换路径段（缓存一年）。
- 描述是中文重写，不等同官方文案；`+` 的措辞按 FUTBIN 的 Playstyle+ 列意译。
- `/playstyles` 是公开页；不挂登录门，不加埋点。
- 窄屏弹层只覆盖 `openable` 的整徽（球员页徽章墙）；表格 compact 与商店内联不走弹层。
- 商店行内说明只给已选中的徽章，不预览未选项。
