# v6.65.2 测试计划 · 签约谈判区每条会话可折叠

判级 **patch**（前端视图态 + 一个派生字段；零迁移、零生产写、无接口语义变更）。
真源：`memory/plan-v6.65.2-nego-collapse.md`（含 grilling 六问裁决）。

## 1. 需求口径

| # | 口径 | 位置 |
|---|---|---|
| 1 | 单条会话默认展开；≥2 条默认全部收起 | `NegotiationsSection.tsx` `active.length < 2 ? open : closed` |
| 2 | 本地记录优先于默认值；按进行中会话裁剪，上限 100 条 | `readStore` / `pruneStore`，键 `whl-nego-fold-v1` |
| 3 | 折叠用 `hidden` 隐藏，不卸载 —— 已填工资、防抖预览、两段式确认必须活着 | `.nego-body hidden={!open}` |
| 4 | 卡头整行可点，但 `a / button / input / textarea / select` 不触发折叠 | `.nego-head` 的 `closest(...)` 守卫 |
| 5 | chevron 是真按钮，`aria-expanded` / `aria-controls` 跟随状态翻转 | `.nego-fold` |
| 6 | 摘要行常驻三段：上次报价 / 预期工资 / 静默剩 Xh | `.nego-sum` |
| 7 | 「有新反馈」= 末轮反馈时间晚于本地记录的最后展开时间，且当前收起 | `whl-nego-seen-v1` |
| 8 | 静默剩余按分钟重算，≤0 显示「即将作废」 | `useMinuteTick` + `silenceText` |
| 9 | `expiresAt` 与到期引擎同源（`SILENT_ANCHOR_SQL` + `negotiation_silence_hours`） | `listMySessions` |

## 2. 用例

| 编号 | 用例 | 预期 |
|---|---|---|
| TC-NC-01 | 两条进行中的会话进入谈判页签 | 两张卡，正文全带 `hidden`，两个 chevron 的 `aria-expanded=false` |
| TC-NC-02 | 点某条 chevron | 该条 `aria-expanded=true`，其 `.nego-body` 去掉 `hidden`，另一条仍收起 |
| TC-NC-03 | 点卡头空白区（h3 非链接区） | 折叠翻转；点 chevron 只翻一次（不发生冒泡双翻） |
| TC-NC-04 | 填工资 5.5 → 收起 → 展开 | 输入框值仍是 5.5（未卸载、未重挂） |
| TC-NC-05 | 本地记 `closed`（单条）+ 一条已回流会话的残留键 | 该条渲染为收起；残留键被删除 |
| TC-NC-06 | 收起 + 末轮反馈晚于 lastSeenAt | 摘要行含「有新反馈」；三段文字齐全 |
| TC-NC-07 | 单条会话（无本地记录） | 默认展开，正文可见 |
| TC-NC-08 | `expiresAt` 为 null | 摘要显示「—」，不显示倒计时 |

## 3. 变异验证（必红靶）

| 靶 | 变异 | 应失败用例 |
|---|---|---|
| M1 | 默认态改回「恒展开」（`stored === undefined ? true : ...`） | TC-NC-01 |
| M2 | 正文改成条件渲染（`{open && ...}`） | TC-NC-04 |
| M3 | 卡头守卫去掉 `closest('a, ...')` | TC-NC-03（点 h3 时被链接抢走不明显，主要靠人工；保留留痕） |

M1/M2 为自动化必红；M3 由于 jsdom 里链接点击会触发路由跳转，改为人工验收第 3 步覆盖。
