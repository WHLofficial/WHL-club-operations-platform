# 测试计划 · v6.64.0 被激活挂牌的在途收入纳入预期收入

需求：被激活挂牌（规则 4.4.2，激活后 5 分钟首价窗）的税后收入纳入预期收入额度，财政页明确说明数额。
计划真源：`memory/plan-v6.64.0-activation-income.md`（grilling Q1-Q4 裁决定案）。

## 需求口径（测试判据的单一真源）

1. 「被激活」判据 = `listings.activated_by IS NOT NULL`（激活动作必带值；未激活/历史无主行不计）。
2. 毛额 = MAX(最高 active 出价, 激活价 ask_price)——激活价保底（grilling Q1），被抢价取更高出价；出价缺失按 0 参与取大（两参 MAX 的 NULL 传播防住）。
3. 税沿用分段累进（现行 active 合同 RC 基数，与过户实算 transfers.ts 同源；forced=0）。
4. status IN ('listed','bidding') 才计；matched_pending 起由 transfers 源②（type='activation'）接管，不重复计。
5. 额度 = Σ净 × k（grilling Q3，统一乘 k 无特例）；available = 余额 − 冻结 + 额度（grilling Q2，三资金触发器同式，迁移 0087 重放）。
6. 财政页「含预期收入 Y m · 其中被激活挂牌 Z m」，Z 与 Y 同口径（×k 后真部分和，grilling Q4），Z>0 才显示；快照出 `activationIncome`（未乘 k）+ `activationCredit`（×k）。
