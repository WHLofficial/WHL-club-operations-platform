## 范围与风险

**In**：
1. `OCR_PROMPT` 要求 `team` 字段输出**中文队名**：JSON 示例值改 `"team": "切尔西"`，并给一条映射示例（CHELSEA → 切尔西、FIORENTINA → 佛罗伦萨、FC BAYERN MÜNCHEN → 拜仁慕尼黑、RB LEIPZIG → RB莱比锡、REAL BETIS → 皇家贝蒂斯）；没有通行中文译名时才照抄截图原文。另增 `teamRaw` 字段（照抄截图上的英文原文，逐字复制、不翻译、看不清填 null；只供用户核对传图对不对，不参与匹配），规则 5 的字符串字段清单同步补 `teamRaw`。
2. `src/core/growth-ocr.ts` 新增队名对侧纯函数：`teamNameKey`（折叠大小写/变音符 → 去空格标点 → 反复剥首尾俱乐部前后缀 `rb/fc/ac/cf/sc/afc/cd/sv/sk/fk/bk/tsv/club/cpu`）、`teamNameMatchStrength`（**强度分层**：3 归一化逐字 / 2 核心名相等 / 1 归一化或核心名互相包含，包含判定要求 ≥2 字）、`isSameTeamName`、`matchOcrTeamSide`（强度高者胜出；**两侧同强度回 `'ambiguous'`**；队名缺失或都不像回 null）；`OcrVision` 增 `teamRaw: string | null` 并由 `parseOcrVision` 宽容解析（缺失/空白/非字符串 → null）。
3. 端点：新增可选入参 `side`（`'home' | 'away'`；带了就跳过队名匹配按指定侧走，非法值 400「side 只能是 home 或 away」）；对不上仍是原 400 文案（加截图原文/中文括注）；歧义回 **400 `code=ocr_team_ambiguous`**，文案「截图队名「FC BAYERN MÜNCHEN」（识别为「慕尼黑」）这场两侧都像（A vs B），分不清主客——请点按钮选边，或换一张队名更完整的截图」。
4. 前端成长录入页：歧义那张渲染成一行提示（**显示模型读到的英文原文**）+「主队 X」/「客队 Y」/「取消（这张图不预填）」三颗按钮 —— 选边用同一张图带 `side` 续跑（不重选文件、其余图结果保留、`tags` 合并不变）；取消 = 该张不预填、不再打服务端、手填内容不动。不猜 = 该张零预填 + 一行提示，绝不默认主队把花名册认到错侧。

**Out**：不落「英文名 → 中文名」映射表（`web/assets/ref/team.json` 696 项 + `clubs.id` 落游戏真号本可搭桥）；不改 `max_tokens`（v6.51.2 已修）；不动 `resolveEntrySide` 与花名册认人（球员名与截图同源，无需桥接）；正常 200 路径的响应形状逐字不变。

**最坏情况口径**：
- 模型不按提示词给中文名（返回英文）⇒ 仍是同一条 400 与既有文案，用户看到的行为**与 v6.51.2 相同**，不会更差；此时用户还可用「选边」按钮靠 `side` 直通救回（本版新增的兜底）。英文兜底属有意取舍：条件式指令已被实测否决，硬编码 20 队英文名会多出一份真名漂移源。
- 译名漂移超出现有容忍（如「慕尼黑1860」被写成「TSV 1860慕尼黑」）⇒ 仍 400 点名，交人工确认，不猜。
- 提示词改动连带把球员名中文化 ⇒ 认人失配（花名册 official 名是 FC26 缩写）—— **已实测排除**（4/4 图球员名保持英文缩写）。
- 核心名剥离过度造成误判 ⇒ 由**强度分层**兜住：只有两侧强度相同才叫歧义（不猜），强度不同必取高者；且只在同场两队（2 个候选）内判定，「曼」这类单字因 <2 字直接不判包含。
- 同城同前缀的两支队（拜仁慕尼黑 / 慕尼黑1860，未来的国际米兰 / AC米兰）⇒ 只写片段（「慕尼黑」「皇家」）两侧同强度 → 400 报「分不清主客」并给出英文原文与三按钮；写全了强度高者胜。
- `side` 被误用（用户选错边）⇒ 预填落在错侧，但该侧花名册与截图球员名对不上，`unmatched` 会列出、用户在面板上可手改或重选；代价显式可见，不会静默改到别处。
- 取消按钮被误点 ⇒ 该张不预填（可再传一次），不影响其余图与已手填内容。

## 登记

**未验证项**：① 生产管理端真机各跑一次识别（探针走的是同模型同提示词，未过端点完整链路：D1 花名册、落侧后的草稿预填、选边续跑与取消按钮）；② 漂移容忍只覆盖生产 20 队名与常见译名，未做 696 队穷举；③ 歧义分支与三按钮在单测里覆盖（TC-EP-14/15/16、TC-ENTRY-E8/E9），**真图 4/4 都给全名、未触发 `'ambiguous'`**，故「用户点选边 / 点取消」这条路径待真机出现时观察。
