## 范围与风险

**In**
- 服务端：`if (!matched)` 分支抛 `HttpError(400, …, 'ocr_team_unmatched')`；文案改为「截图队名「X」{（识别为「Y」）}对不上这场比赛（A vs B）——确实是这张图的队名，就点按钮选边；传错图请点取消」。
- 前端：`runOcr` 的 catch 同时认 `ocr_team_ambiguous` 与 `ocr_team_unmatched` ⇒ 两条路共用同一条待选行（提示 + 主队/客队/取消三颗按钮），选边用同一份 base64 续跑、取消则不预填。
- 保持既有语义：`side` 直通（同一张图带 `side` 重发直接跳过队名匹配）；`side` 非法 400「side 只能是 home 或 away（省略则按截图队名自动判断）」。
- **英文名兜底分侧（并入项）**：`src/core/fc26-team-names.ts` 镜像 `web/assets/ref/team.json`（696 条 `{id, name}`，`clubs.id` = FC26 队号）；`fc26TeamIdOfName` 两趟匹配——严格层（逐字 / 剥俱乐部前后缀的核心名相等）优先，严格层全空才退宽松包含，**唯一命中才算**；端点里**中文命中优先**，中文落空或歧义时才用 `teamRaw ?? team` 的英文原文查队号、与本场两侧 `clubId` 对齐，命中即走常规认人路径。
- 顺带：两侧 `resolveEntrySide` 从「判侧一次 + 取花名册再查一次」合并为一次（同一份缓存），OCR 面板请求的库查询少一次。

**Out（有意不做 / 覆盖不到）**
- 姓名拼写容错层（用户先前裁决「暂时不做」）。
- 游戏内显示假名的 4 支（Milano FC / Lombardia FC / Bergamo Calcio / Latium）：镜像存的是改回后的真名 ⇒ 截图给假名查不到，落回按钮选边（这几支里只有 AC米兰(CPU) 在现役联赛，且 CPU 侧花名册本就为空）。
- CPU 俱乐部的英文名桥接（`AC Milan` 在镜像里对应老 id 47 与新 id 131681 两条同名 ⇒ 多命中不猜；`resolveEntrySide` 对 CPU 队直接返回 `clubId: null`，桥接无从对齐）。
- 不改提示词/模型（英文译名逃逸口仍在：模型对冷门队可能照抄原文——现在照抄也多半能被镜像接住）。

**最坏情况口径**
| 场景 | 结果 |
| --- | --- |
| 模型给了冷门队英文名（如 OLYMPIACOS FC） | 先用镜像查队号自动判侧 ⇒ 直接预填（不再落红字）；镜像查不到时才退到提示行 + 三颗按钮 |
| 同一英文名对上一支不含该队的场次 | 不硬塞：照旧 400 `ocr_team_unmatched` + 按钮（测试 TC-EP-18 第二段钉住） |
| 中文与英文两个来源指向不同侧 | 以中文为准（测试 TC-EP-18 第三段钉住），不做二义性提示 |
| 用户确实传错图（别的比赛） | 点「取消（这张图不预填）」：不预填、不再打服务端、手填内容不动 |
| 用户点错侧 | 预填落错队（花名册按该侧俱乐部取）——与 v6.51.3 歧义选边同口径：按钮文案带队名，且保存前可改 |
| 模型直接给了中文名 | 走自动判侧成功路径，行为与 v6.51.7 之前逐字相同（不出现待选行） |

## 登记

**未验证项**
1. 用户侧真机验收：重传那两张图（奥林匹亚科斯 / 皇家马德里）——正常情况下应直接预填（`OLYMPIACOS FC` 可由镜像查回 280 自动判侧），只有镜像认不出时才出现提示行 + 三颗按钮（待执行）。
2. 英文名兜底只在单测/夹具里验证过（真实模型给 `OLYMPIACOS FC` 的形态来自用户报障截图）；镜像对**冷门队译名差异**（模型自作主张换个写法）不参与判定，仍走选边兜底。
3. 兜底分侧的三处覆盖不到已登记在 Out：游戏假名 4 队、CPU 英文名多命中、拼写容错层（未做）。

**口径**
1. 「队名对不上」不等于「这张图不能用」：识别已成功（rows/数字/页签都在），只是分侧失败 ⇒ 一律给人为分侧的机会。
2. 两个 code 语义分工：`ocr_team_ambiguous` = 两侧都像（分不清）；`ocr_team_unmatched` = 两侧都不像（含模型给英文名）。前端对两者行为一致。
3. 取消 = 不预填、不重发（`calls` 不增加），与 v6.51.3 一致。
4. 分侧优先级固定：中文识别结果 → 英文镜像兜底 → 按钮选边（同一次识别里三者按此顺序判定，TC-EP-18 第三段钉住「两来源打架以中文为准」）。
