# 测试计划 · v6.50.0 海捞两阶段（暗标段密封标 + 明标段原样）

增量计划与设计稿：`memory/plan-v6.50.0-sea-sealed.md`、`memory/design-sea-two-phase.md`（口径 12 条 + 落地偏差记录）。

## 范围与风险

**范围**：① 迁移 `0070_sea_sealed.sql`：`sea_batches`（一窗一批）+ `sea_sealed_bids`（同球员同队唯一）+ `fund_holds` 密封冻结守卫触发器 + `transfers.sealed_bid_id`（部分唯一索引）+ 单据终态释放/结算触发器；② `src/worker/sea-sealed.ts`：阶段判定 / 批次惰性创建 / 出标改标撤回（单批原子）/ 开标（重跑资格链 → 建待审单 → 幂等 claim → 批次 `opened`）/ 关窗立即开标 / 到点开标 / 24h 提醒 / 管理端三操作；③ 到期末引擎注册第三适配器 + `closeWindow` 钩子；④ 通知 4 模板 + 两枚 config 键；⑤ 教练侧三端点 + 海捞页阶段横幅 + 球员档案 E 态密封标表单；⑥ 管理端四端点 + 转会页「海捞暗标段」段。

**安全默认（最重要的回归口径）**：`sea_enabled` 默认 `false` ⇒ 阶段判定不生效、常规海捞入口照旧、收标中的批次会被 tick 整批作废并解冻；时刻表 `transfer_sea_sealed` 行默认 `none/none` 且**随窗锚不开批次**（统一截止必须是具体时间）⇒ 双保险下上线行为与上线前逐字一致。开标只建 `pending_review` 单，**签入费在审核通过时才收**（与现有海捞同口径），冻结在该时点由 `settled` 销毁，谈判期内可用额不被双重扣减。

## 自动化用例（vitest）

### `tests/sea-sealed.test.ts`（25 例，五组）

1. **阶段与惰性建批（4）**：默认关闭 ⇒ 阶段 `off` + 常规海捞 409 `sea_disabled` 且零标；时段内建唯一批次（重复读不建第二份）+ 倒计时与窗口引用就位；行不限制 ⇒ `sea_not_sealed` 不开批次；终随窗锚 ⇒ 不开批次（`state='none'`）。
2. **密封标（5）**：首标 30% 冻结（`ref_type='sea_sealed'`，`ref_id=bid.id`）+ 审计 `sea_sealed_bid`（`actor` = 教练、`origin='user'`）+ 他队看不到我的标；重复出标=改标（1 行新冻结按新价、旧冻结 `released`）；可用额不足 ⇒ 400 `sea_no_funds` 且零孤儿标行；撤回 ⇒ `withdrawn` + 解冻 + 再出标 409 `sea_bid_resolved`；本窗被解约的球员 ⇒ 409 拒绝。
3. **开标（5）**：价高者得（胜出建 `free_agent/pending_review`、`fee` = 新违约金、`sealed_bid_id` 回链 + 1 张 `review_task` + 批次 `opened`；胜出方收 `sea_sealed_lead` 带金额、败者收 `sea_sealed_lost` 不含金额且文案含「更高」）；同额取最早；收标期间被挂牌 ⇒ 整组作废、双方解冻、零 `transfers`；幂等重开 ⇒ `already:true`、只 1 单、只 1 次审计；开标后公示就位 + 再出标 409 `sea_batch_resolved`。
4. **触发点（4）**：关窗仍 sealed ⇒ 立即开标（窗口 `closed` + 批次 `opened` + 关窗后仍能建 `season 4 / window_seq 1` 的待审单 + 审计 `after.reason='window_close'`）；到点 `runExpiryTick` ⇒ `byAdapter.sea_sealed=1`；提前 24h 提醒（`reminded_at` 抢占、只发有标的队、第二跳零重复）；`sea_enabled=false` ⇒ 批次 `cancelled` + 标全部作废（原因「海捞两阶段已关闭，本批标作废」）+ 解冻。
5. **衔接·守卫·结算·管理端（7）**：收标期内常规海捞 409 `sea_sealed_phase`（取消批次后 201）；四个迁移对象（两触发器 / 两唯一索引）在 `sqlite_master` 且守卫真会抛（`WHL_SEA_REJECT_CLOSED` / `_AMOUNT` / 同 `sealed_bid_id` 第二单 UNIQUE）；审核通过 ⇒ 划签入费 + 冻结 `settled` + `transfers='signing'`；审核驳回 ⇒ 冻结 `released` + 标 `void`；管理端明账（按球员/金额排序 + summary）；延长（批次与时刻表同改、过去时间 400）；取消（全部作废 + 解冻 + 教练侧回 `none`）。
