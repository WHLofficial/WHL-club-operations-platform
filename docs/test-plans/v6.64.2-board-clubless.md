# v6.64.2 测试计划 · 无东家的名单行把广告板打白屏

- **版本**：v6.64.2（patch，零迁移、零新端点）
- **判级理由**：修线上白屏故障；`GET /api/market/transfer-board` 响应字段不变，只是名单口径收紧一行（`AND p.club_id IS NOT NULL`）；解约完成语句多清六个挂牌字段，属同一交易内的一致性修补。
- **涉及面**：`web/src/components/TeamLogo.tsx`、`web/src/pages/market/MarketAdBoardPage.tsx`、`web/src/lib/api.ts`（类型）、`src/worker/routes/market.ts`（广告板 SQL）、`src/worker/transfers.ts`（解约完成语句）。

## 1. 需求真源（口径表）

| # | 口径 | 落地位置 |
|---|------|----------|
| 1 | 队名缺失（null）时 `TeamLogo` 不得抛错，色块首字兜底「—」，`alt` 兜底「未知球队」 | `web/src/components/TeamLogo.tsx` |
| 2 | 广告板卡面不得把 `clubName` 打成字面量 `null` | `MarketAdBoardPage.tsx` `subline()` |
| 3 | `TransferBoardRow` 的类型必须照真实载荷写（`clubId` / `clubName` 可空），不许再骗过 typecheck | `web/src/lib/api.ts` |
| 4 | 广告板只收有东家的球员：`transfer_listed = 1 AND club_id IS NOT NULL`，`total` 同步 | `src/worker/routes/market.ts` |
| 5 | 解约完成即清挂牌：`transfer_listed=0`、`list_price`/`min_offer_price`/`transfer_listed_at` 置 NULL、`offer_auto`/`not_for_sale` 归 0 | `src/worker/transfers.ts` |
| 6 | 历史脏数据不回魂：限流缓存（KV，1h）里旧载荷仍带 null 行时，前端也必须正常渲染 | 口径 1 + 2 |

## 2. 范围

**In**：广告板页面渲染、广告板端点名单口径、解约完成后的球员挂牌字段、`TeamLogo` 空队名兜底。

**Out**：错误边界（全局 ErrorBoundary）本次不做；`ensureNotInFlight` 的 signing 缺口、球员换队时的挂牌继承不在本版；生产 player 90 的脏标记清理需另开数据变更单。
