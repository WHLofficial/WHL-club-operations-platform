# v6.60.11 测试计划 · 兼任本队教练的管理账号能自己选成长方案

起因（用户口径）：「我作为超管和里昂教练，怎么不能选我队人的成长方案？」。

范围：球员页成长页签的写入口（选升级方案、发中国计划徽章），前端 `GrowthBlock.canManage` 与两个服务端端点。

## 判据

教练身份以认证中心绑定为准（`getBoundClub(user).id === player.club_id`），与角色无关：

| 账号形状 | 写入口 |
| --- | --- |
| 教练，绑定的是球员现属俱乐部 | 可写（v6.60.5 起如此） |
| 教练，绑定的是别队 / 没绑定 | 只读 + 「只有球员所属俱乐部的教练能选升级方案。」 |
| 管理账号，同时绑定了球员现属俱乐部（超管兼本队教练） | **可写**（v6.60.11 起，v6.60.5—v6.60.10 被角色挡死） |
| 管理账号，没绑定或绑的是别队 | 只读（「管理组不能代办」的初衷不变） |
