## 2. 用例

### TC-TONE-01 · shade 适用域锁（vitest，`club-cards.test.ts`）
- **前置**：CARD_VIEW_CELLS 已加载。
- **步骤/预期**：`ca.shade(row)=45`、`pa.shade(row)=92`、`baseCa.shade(row)=88`；`age / growthGap / wage / years / influence` 的 `shade` 为 `undefined`（差值/金额/效力/文本不套色——套了会把 30 的差值读成「弱」）；`shade` 对 nullish 值返回 null ⇒ 渲染层中性。

### TC-TONE-02 · 值格渲染类锁（vitest，`card-parts.test.tsx`）
- **步骤/预期**：SquadCard 基本视图：缺值格显 `—` 且类不带 `attr-*`；PA 92 → `attr-good`；抽样 62 → `attr-mid`（attrClass 阈值 ≤50 bad / ≤60 weak / ≤70 mid / ≤80 solid）；年龄格无色。

### TC-LAYOUT-01 · 两行式排版锁（e2e ⑨ 观众态 / ⑲ 教练态）
- **⑨**（375 视口）：`.sqc-id` 容器宽 ≥96px（min-width 生效、值区必折第二行）；
- **⑲**（375 教练态）：`mBasis === '75%'`、`margin-left` 计算值 ≥60px（`auto` 用后像素）、值区 `rows===1` 单行、零溢出、组头尾格错位 ≤3px、徽章与名字 top 差 ≤3px（同行）、`nmW ≥150`。

### TC-UNIT-01 · 效力单位「年」（vitest + e2e）
- `club-cards.test.ts` 取值口径：`contract.get` 出 `1.5年`；`players-library.test.ts` chip `效力时长 ≥ 1.5 年`；`club-columns.test.ts` 横表 `1.5 年`；`PlayersLibrary.test.tsx` chip 按钮 aria `移除筛选：效力时长 ≥ 0 年`；e2e ⑨ contractVals 断言 `3年`；`clubs-detail.test.ts` 只按 key 数 count（label 不锁）。
