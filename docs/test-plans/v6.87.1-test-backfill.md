## 5. 偏差与风险

1. **TC-ORD-03 未实施**：原要求改码前后五表金样逐格比对；v6.83 已上线，前态无法回溯。计划允许的替代方案（当前态六链金样）本批未写——它只能锁未来漂移、不能证明 v6.83 当次等价，且与既有 21 例矩阵/列集/批序锁高度重叠。**登记为遗留**，若需要严格历史金样，应在临时 worktree 检出 `81c3f4d^` 跑同一 harness 取基线。
2. **锁的文本脆性**：273 导出、43 锚点、30–40 行漂移断言会随正常契约重构变红；改契约时必须同步改锁，这是设计意图（锁不是实现）。
3. **MV-04 / MV-06 的教训**：源码锁的「整文件 toContain」会被同词/同名字段互保，必须把断言缩到目标接口体或目标纪律行。两处已在本批加固。
4. M7 / M11 属等价性变异：M7 只靠批内下标锁抓，M11 只靠文本锁抓，行为测试不红是设计使然。
5. 工作区并行会话 `scripts/prod-*` 脏文件全程未触碰；本批提交只 add 上述三测试文件与本 docs/版本文件。
