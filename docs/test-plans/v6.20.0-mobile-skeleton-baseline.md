## 范围

**In scope**
- ① 管理端侧栏抽屉（≤760px）：`admin-nav-toggle` 切换钮（仅窄屏渲染，文案「☰ 管理导航 · 当前页名」）、`.admin-sidebar.open` 左滑抽屉、`admin-drawer-mask` / `admin-drawer-close` 类名契约；× / Esc / 遮罩三条关闭路 + 路由切换自动关；背景 inert 焦点陷阱；`overscroll-behavior: contain` 锁滚。
- ② 公开顶栏 ≤640 收纳：导航行两侧渐隐边缘提示；active tab 路由变化时 `scrollIntoView({inline:'center', block:'nearest'})` 横向滚入；两行布局（v2.3.0 定式）不变、公开端不加汉堡。
- ③ 全站保底横扫：一切 `<table>` 必包 `.table-wrap`（CoachPanel ×4、admin MarketPage/EventsPage/SeasonsPage 各 ×3、OverviewPage ×2、SystemPage、market 三页等，实现时全仓 grep 穷尽）；TSX 内联固定 width/minWidth 清除（BrandsPage 六处、SystemPage `18rem`、OverviewPage `9rem`、CoachPanel `90px` 等）；长文本硬 nowrap 去除；`styles.css` 固定 min-width 八处逐条裁量；扫描首跑暴露的残余破版页属本批交付范围。
- ④ e2e 闸门：检查 ⑫ 全路由 375×812 扫描断言 `doc.scrollWidth ≤ doc.clientWidth + 1`；检查 ⑬ 管理抽屉四路径开合。
- 回归：桌面（管理端 >760、公开端 ≥641）DOM 与样式零变化；既有 e2e 11 例、vitest 1194 例、typecheck、build 全绿。

**Out of scope**
- 编辑页卡片化重排（成长录入 11 列花名册、BrandsPage/Imports 表单重排、CoachPanel 32 列粘性首列/列分组）→ v6.21.0。
- 公开阅读页卡片化（Player dossier、ClubDetail、market 四页）+ iOS 真机抽验轮 → v6.22.0（本批只留 P2 登记项，见 TC-REG-06）。
- `.admin-shell` 760 与球员库 900 两套断点统一（spec §5：动存量风险 > 收益，本批不改）。
- v3.1.0 遗留「`aria-modal` 顶栏在 `<Routes>` 外不在 inert 区」：新抽屉照抄同款范式、一并遗留（spec §5，v6.22 真机轮一并看）——不在本批断言范围，只作 TC-DRW-08 备注。
- 后端 / 迁移 / 新依赖 / 运行时 CSS-in-JS / 浏览器兼容矩阵（沿用 e2e 单 Chrome 惯例）。

## 最坏情况口径（铁律）

- **本批「通过」的失败场景定义（整批口径）**：375×812 全路由扫描中**任何一条**路由出现 `scrollWidth > clientWidth + 1` → 整批不通过。不得按「个别页面」「历史遗留」豁免，不得用白名单/跳过把红扫绿；扫描首跑暴露的残余破版页属本批交付范围，只能修绿不能登记（spec §3）。
- **桌面零变化铁律**：>760（管理端）/ ≥641（公开端）任一 DOM 节点、类名序列或关键计算样式相对批前变化（例：切换钮渲染进桌面 DOM、抽屉痕迹留在宽屏）→ 违反铁律，整批不通过（spec §2 P-桌面零变化）。桌面项分级归 P2，失败判定与 P0 同级。
- **抽屉不可用最坏情形**：三条关闭路（× / Esc / 遮罩）与路由切换自动关任一失效 → 移动端把用户困在抽屉里；若同时锁滚生效，页面直接不可用。→ TC-DRW-04/05/06/07 各自独立断言，不能只测「能开」。
- **焦点陷阱缺失**：背景未 inert → Tab 焦点逃到 `admin-main`，键控/VoiceOver 用户陷入未知位置。→ TC-DRW-08 断言焦点始终留在抽屉内；顶栏不在 inert 区属登记遗留，须被焦点循环挡在外。
- **锁滚测不出风险（increment26 教训）**：headless Chrome 滚动条宽 0，`body{overflow:hidden}` 的横跳与 iOS 上的不彻底**测不出来**——该断言必须走人工（Windows 可见滚动条 + 真机），e2e 只作旁证。→ TC-DRW-09 / TC-REG-06。
- **`scrollIntoView` 无断言风险**：去掉 `scrollIntoView` 后 ⑫ 不会红（active tab 只是不在可视区，页面并不溢出）→ 必须靠 TC-TOP-03 的几何断言兜住；若实现未落该断言，人工口径见变异 V3，不得当「已覆盖」。
- **表格保底只包不断言 = 假绿**：`.table-wrap` 包裹存在但 `overflow-x` 被页面级覆盖或未生效时，375 仍溢出 → 代码扫描（TC-SWP-01）与实际几何（TC-E2E-01）双口径，缺一不可。
- **扫描穷尽性**：静态扫描必须覆盖 `web/src` 全树（实现口径 = 全仓 grep 穷尽），不能只查 spec 点名的已知页；否则漏网表假绿（变异 V6）。
- **断点边界**：三档并存（640 / 760 / 900），边界必须双侧验证（760/761、640/641），避免「375 测过就以为桌面也对」。
- **e2e 失败态（铁律要求补失败态）**：⑫ 的失败态 = 故意注入固定宽元素必须红（TC-E2E-02）；⑬ 的失败态 = 类名契约写错必须红（变异 V2）。
- **单测测最大组**：扫描类用例的「最大组」= 全树文件集合（非抽样清单）；实现量取 `web/src` 文件数并断言扫描器遍历到全部 `*.tsx`（漏一个文件不得静默通过）。

## 用例

### TC-DRW 管理端侧栏抽屉（≤760px）

**TC-DRW-01 · 切换钮窄屏渲染、宽屏不渲染（含 760/761 边界）**（P0 · e2e）
- 前置：`npm run build` + `npm run dev`（8791），管理员登录态；视口 375×812、1280×900，另在 760 与 761 各开一次。
- 步骤：375 打开 `/admin` 量 `admin-nav-toggle` 存在且可见；1280 同页量该节点不在 DOM；760 / 761 各重载一次对比。
- 预期：≤760 存在且可见；>760（含 761）DOM 中不存在（不是 `display:none`，是未渲染）；761 下 `.admin-sidebar` 保持桌面侧栏形态。

**TC-DRW-02 · 钮文案带当前页名**（P1 · e2e）
- 前置：375 视口（同 TC-DRW-01）。
- 步骤：依次进 `/admin`（总览）与 `/admin/players`，读 `admin-nav-toggle` 文本。
- 预期：文本形如「☰ 管理导航 · <当前页名>」，页名与侧栏 active 项一致；路由切换后名称随动，不残留上一页名。

**TC-DRW-03 · 点按钮开抽屉（类名契约）**（P0 · e2e，⑬ 第 1 步）
- 前置：375 视口任一 /admin 子页（同 TC-DRW-01）。
- 步骤：点 `admin-nav-toggle`。
- 预期：`.admin-sidebar.open` 出现；`admin-drawer-mask` 出现；`admin-drawer-close` 可见可点；抽屉自屏幕左侧滑入。

**TC-DRW-04 · 点链接导航 + 自动关**（P0 · e2e，⑬ 第 2 步）
- 前置：抽屉已开（同 TC-DRW-03）。
- 步骤：点抽屉内非当前页导航项（如「赛季管理」）；再从其他子页直链进入本页一次。
- 预期：URL 变为该路由、页面内容切换；抽屉 `.open` 消失、mask 消失；无整页刷新；从任意来源进入子页时抽屉不残留 `.open`。

**TC-DRW-05 · Esc 关**（P0 · e2e，⑬ 第 3 步）
- 前置：375 视口。
- 步骤：开抽屉 → 按 Escape；再开一次，先让焦点落在抽屉内某导航项上，再按 Escape。
- 预期：两种焦点位置下均关闭；关闭后焦点回到 `admin-nav-toggle`。

**TC-DRW-06 · 遮罩点关**（P0 · e2e，⑬ 第 4 步）
- 前置：375 视口。
- 步骤：开抽屉 → 点 `admin-drawer-mask`；再开一次点抽屉内容区。
- 预期：点遮罩关闭；点抽屉内容区不误关。

**TC-DRW-07 · × 关**（P1 · e2e）
- 前置：375 视口。
- 步骤：开抽屉 → 点 `admin-drawer-close`。
- 预期：关闭、焦点回 `admin-nav-toggle`；行为与 Esc 路径一致（均解锁锁滚）。

**TC-DRW-08 · 背景 inert 与焦点陷阱**（P0 · e2e + 人工核验）
- 前置：375 视口，抽屉已开。
- 步骤：读背景容器（`admin-main` 等）是否 `inert`（或等价机制）；连按 Tab ≥20 次、再 Shift+Tab ≥10 次；关闭抽屉后再 Tab。
- 预期：Tab/Shift+Tab 循环始终在抽屉内，不落到背景内容；关闭后 inert 解除、背景恢复可 Tab。备注：顶栏在 `<Routes>` 外不在 inert 区属 spec §5 登记遗留，须被焦点循环挡在外面，不作为本批失败点。

**TC-DRW-09 · 锁滚与关闭后复原（无横跳）**（P0 · 人工：本机 Chrome devtools 375 视口 + 真机）
- 前置：Windows 本机（经典可见滚动条）与 iOS/Android 真机各一；抽屉所在页内容足够长可滚。
- 步骤：开抽屉 → 尝试滚动背景；量开关前后 `document.documentElement.clientWidth`；关抽屉后再滚。
- 预期：抽屉打开时背景不可滚（锁滚生效 + `overscroll-behavior: contain` 兜底）；开/关前后 `clientWidth` 不变（无横跳）；关闭后页面可正常滚动、位置不残留。
- 备注：headless 滚动条宽 0、iOS 不彻底，e2e 测不出——本项人工执行；真机销遗留见 TC-REG-06。

**TC-DRW-10 · 抽屉交互目标 ≥36×36**（P1 · 人工 devtools〔e2e boundingBox 可选〕）
- 前置：375 视口，抽屉已开。
- 步骤：量 11 个导航项与 `admin-nav-toggle`、`admin-drawer-close` 的命中区尺寸与相邻间距。
- 预期：任一交互目标 ≥36×36（spec §2 P-触控目标）；相邻目标不重叠到易误触。

### TC-TOP 公开顶栏收纳（≤640px）

**TC-TOP-01 · 两行布局保持**（P0 · e2e）
- 前置：375×812 与 640 两档，公开路由（如 `/players`）。
- 步骤：量顶栏行数、导航行是否换第三行/裁剪；与 641 对照。
- 预期：≤640 仍两行（标题/操作行 + 导航行），导航行不换第三行、内容不被裁切；结构与 v2.3.0 定式一致。

**TC-TOP-02 · 导航行两侧渐隐边缘提示**（P1 · 人工：devtools 375）
- 前置：375 视口，导航 tab 总宽超出可视区（9 个 tab 必然超出）。
- 步骤：在 `/players` 观察导航行两侧；把 tab 行滚到最左、最右与中间，分别看提示。
- 预期：有未显示内容的一侧显示渐隐提示、到头一侧提示消失；提示不拦截 tab 点击（命中正常）。

**TC-TOP-03 · active tab 自动滚入**（P0 · e2e）
- 前置：375 视口；取样深链 `/admin` 或点最后一个 tab「管理端」。
- 步骤：从 `/players` 直链进 `/admin`（或等价路由切换），读两个页面各自 active tab 相对导航行可视区的 boundingBox。
- 预期：active tab 落在导航行可视范围内（居中优先）；页面纵向不跳（`block:'nearest'` 语义）；每次路由变化后都生效，不只在首次挂载。

**TC-TOP-04 · 公开端不加汉堡**（P1 · e2e）
- 前置：375 视口，公开路由逐条。
- 步骤：扫描公开顶栏是否存在导航汉堡/抽屉入口。
- 预期：不存在（spec §2 P-顶栏：9 个 tab 横滑快切优于抽屉）；导航行仍为可横滑 tab 行。

**TC-TOP-05 · 断点边界 640/641**（P1 · e2e）
- 前置：640 与 641 两档。
- 步骤：各扫一次 `/players`。
- 预期：640 走两行 + 收纳语义；641 单行桌面顶栏原样（无渐隐、无两行折叠）；两侧均零溢出。

### TC-SWP 全站保底横扫（静态 + 人工）

**TC-SWP-01 · `<table>` 穷尽包裹 `.table-wrap`**（P0 · vitest 静态扫描）
- 前置：扫描 `web/src/**/*.tsx` 全树。
- 步骤：列出全部 `<table` 出现处，逐处向上追溯 `.table-wrap` 祖先并断言；对 spec 已知清单（CoachPanel ×4、admin MarketPage/EventsPage/SeasonsPage 各 ×3、OverviewPage ×2、SystemPage、market 三页等）逐一核对。
- 预期：零裸表；已知清单与扫描结果一致（清单只作抽验，不作白名单）；扫描器遍历文件数 = 全树 `*.tsx` 数（不抽样）。

**TC-SWP-02 · TSX 内联固定 width/minWidth 清除**（P1 · vitest 静态扫描）
- 前置：扫描 `web/src/**/*.tsx`。
- 步骤：扫 `style={{…}}` 内联 `width`/`minWidth` 的固定像素/rem 值（BrandsPage 六处、SystemPage `18rem`、OverviewPage `9rem`、CoachPanel `90px` 等）；每处改流式 / `min(N, 100%)`，或进白名单登记理由（短数字/徽章豁免，spec §2 P-固定宽禁令）。
- 预期：命中为零（白名单除外，白名单条数在测试内显式常量、带注释）；浮层/下拉面板为 `min(N, 86vw)` 形态。

**TC-SWP-03 · 长文本硬 nowrap 去除**（P1 · vitest 静态扫描 + 人工抽查）
- 前置：扫描 TSX 与 `styles.css`。
- 步骤：列出全部 `white-space: nowrap`，逐条区分「短数字/徽章（可留）」与「姓名/队名/长文案（必去）」。
- 预期：长文本项清零；保留项白名单有理由（spec：短数字/徽章 nowrap 无害）。

**TC-SWP-04 · styles.css 固定 min-width 八处逐条裁量**（P1 · vitest 静态扫描 + 人工）
- 前置：`web/src/styles.css`。
- 步骤：列出全部固定 `min-width`；对照 spec §0 的八处清单逐条给结论（流式 / `min(N, 100%)` / 保留并说明）。
- 预期：无未裁量项；改流式后对应组件 375 不溢出（由 TC-E2E-01 兜底）。

**TC-SWP-05 · 表格横滚逃逸口可用**（P1 · 人工 devtools 375）
- 前置：375 视口，打开逸出表格页（CoachPanel、admin 三个列表页、market 三页）。
- 步骤：横向滚 `.table-wrap` 到最右，检查最后列可达；用 devtools 检查包裹层 `overflow-x` 实际生效值。
- 预期：内容可完整滚出、无父容器裁切；两侧渐隐提示与可滚方向一致（spec §2 P-表格保底）；不引发整页横滚（整页几何由 ⑫ 断言）。

**TC-SWP-06 · 横扫穷尽性与残余破版页收口**（P1 · 人工：代码评审）
- 前置：本批完整 diff 可读。
- 步骤：评审全仓 grep 表/固定宽清单是否穷尽（含 spec 未点名页）；⑫ 首跑暴露的溢出路由逐页修绿；检查扫描与 e2e 未引入路由白名单/跳过。
- 预期：溢出清单清零、零豁免；遗漏项显式登记，不静默丢弃。

### TC-E2E e2e 闸门（⑫ / ⑬）

**TC-E2E-01 · ⑫ 全路由 375×812 零溢出**（P0 · e2e）
- 前置：`npm run build` → `npm run dev`（8791）；`E2E_PERSIST_TO` 与 dev 一致；沿用 smoke 现有打桩（本机 TOUR_DB 旧 schema 的球队端点 `page.route()`）与噪声白名单（仅 500 且路径精确匹配）。
- 步骤：375×812 逐条打开：公开路由（`/`、`/players`、`/clubs`、`/market` 四页 = `/market` `/market/free` `/market/intel` `/market/mine`、`/negotiations`、`/offers`、`/ledger`、`/notifications`、`/club`、`/bind`；需登录/重定向的以重定向后终态扫描）+ 详情页取样 2 条（`/players/:id`、`/clubs/:id`，id 从列表页首行取，不硬编码）+ admin 11 子页（`/admin`、`/admin/seasons`、`/admin/players`、`/admin/growth`、`/admin/imports`、`/admin/market`、`/admin/clubs`、`/admin/brands`、`/admin/events`、`/admin/finance`、`/admin/system`）；每页等数据落地后读 `doc.scrollWidth` / `doc.clientWidth`。
- 预期：每页 `scrollWidth ≤ clientWidth + 1`；任一页超限即检查红，且输出**点名路由**（不是笼统一句失败）。

**TC-E2E-02 · ⑫ 失败态：注入固定宽必红**（P1 · e2e 自检）
- 前置：⑫ 已能跑绿。
- 步骤：临时在任一被测页注入 `width: 4000px` 元素（或复用变异 V1 的裸表）重跑 ⑫，再撤掉重跑。
- 预期：注入时红且点名该路由，撤销后转绿——证明 ⑫ 不是「永远绿的空断言」。

**TC-E2E-03 · ⑬ 抽屉四路径与编号共存**（P0 · e2e）
- 前置：同上（build + dev + 登录态）。
- 步骤：同一跑内执行 ⑬：点 `admin-nav-toggle` 开 → 点链接导航（URL 变化 + `.open` 消失）→ 再开按 Esc 关 → 再开点 mask 关。
- 预期：四路径全过；⑫⑬ 追加在既有 ①–⑪ 之后，旧检查编号与输出不变（含 ⑧⑨ 的 `docOverflow` 口径）。
