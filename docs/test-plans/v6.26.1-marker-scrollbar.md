# 测试计划 · v6.26.1（绿标「练满去标」+ 球员库吸底横向滚动条 + TopBar 消费中心入口）

> 设计：qa-test-planner（2026-10-03）。执行层：vitest（引擎级 / 端点级）+ e2e smoke + 变异验证（最坏情况口径）。基线：v6.26.0 发布时 vitest 75 文件 / 1297 例、e2e 21/21。

## 1. 范围

**In**：① 🟢 growth 标记判定加「未练满」（现值 `ca < pa`）——JS 纯函数 `markerOf`、SQL 同源表达式 `markerWeightSql`、注册合规 `checkSquad` growth 名额三处同步；迁移 `0061` 重建 `idx_players_sort_marker`。② 球员库表格吸底镜像横向滚动条（`StickyScrollbar` 组件，桌面 >900px）。③ TopBar 加「消费中心」NavLink。

**Out**：`growable` 的即时重算（仍走赛季结算/建季，不改）；买 PA 在练满但 growable 未重算期间的放行语义（PA 抬高后绿标回归，设计使然）；其余 50+ `.table-wrap` 页面的滚动条挂载（组件通用，后续按需）；🔴🟡 判定（不动）。
