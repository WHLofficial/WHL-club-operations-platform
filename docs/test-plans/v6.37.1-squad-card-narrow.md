# 测试计划 · v6.37.1 球队卡窄屏压缩修复（squad-card-narrow）

设计依据：真机四截图（2026-10-06，~360-393 逻辑px）+ 根因宽度账。执行层：vitest（club-cards.test.ts、ClubDetail.test.tsx）+ e2e（scripts/e2e/smoke.mjs ⑨）+ 变异验证。
基线：v6.37.0 上线后 vitest 103 文件 / 1726 例、e2e 23/23。

## 范围

- **在范围内**：窄屏卡片指标区网格化（`--sqc-mcols`：basic 2 / growth 3 / contract 2 / market 3）、合同列宽 52→60px、值格 nowrap、副行 flex-wrap、效力值「N 赛季」→「N赛季」。
- **不在范围内**：桌面 wide 变体（既有 `.sqc-card.wide .sqc-m` flex 覆盖，逐列对齐不适用）、球员库/球员页的赛季文本（表格单元格空间充足，保留空格）、D1/后端零改动。

预期：`CARD_VIEW_CELLS.contract` 的 years 取值 = `String(n) + '赛季'`（如 `1.5赛季`、`0.5赛季`）；serviceSeasons null 出 null。
位置：web/src/lib/club-cards.test.ts「取值口径」例。

### TC-SQC-NW-02 网格列配置映射（P0，vitest）
预期：`VIEW_GRID_COLS = { basic: 2, growth: 3, contract: 2, market: 3 }`，与 `VIEW_COL_WIDTH` 键集一致；contract 列宽 `60px`（配 nowrap 兜住最长「10.5赛季」）。
位置：web/src/lib/club-cards.test.ts「窄屏网格列配置」例。

### TC-SQC-NW-03 桌面 13 列值序列（P0，vitest 回归）

### TC-SQC-NW-04 窄屏名字区不被压成逐字竖排（P0，e2e）

### TC-SQC-NW-05 位置摘要不被压没（P0，e2e）

### TC-SQC-NW-07 合同视图值序列（P0，e2e 回归）

## 最坏情况口径

- 宽度断言取**最小可行阈值**（100px ≈ 8 字符两行 + 副行完整的最小空间）而非当次实测值——视口、字体渲染漂移不误伤。
- 320px 超窄验证入宽度账：合同 2×60=120 ⇒ 名字区 ~136px 仍 ≥100px；市场 3×52=156 ⇒ ~100px 贴线（3 列视图不变换）。
- 变异按「将来最可能的重构方式」：删整个 `--sqc-mcols` 下发（而不是改一个数字）、列宽回旧值。
