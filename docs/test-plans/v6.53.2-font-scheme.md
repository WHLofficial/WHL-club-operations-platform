## 1. 锁定口径

| # | 口径 |
| --- | --- |
| 1 | 三套角色：标题 `--font-display`（Noto Serif SC 600 子集）/ 正文 `--font-sans`（Inter 拉丁 + 系统黑体）/ 数字 `--font-mono`（JetBrains Mono，栈首） |
| 2 | 中文正文**不自托管**；品牌辨识度由标题宋体 + 数字等宽 + 配色承担 |
| 3 | 标题只允许 600（子集仅此一档），`h1/h2/h3` 统一；不得出现 700/800 合成粗体 |
| 4 | 只 preload `inter-latin.woff2`；298KB 宋体不 preload |
| 5 | Inter / JetBrains 的 latin-ext 用独立 `unicode-range`，无对应字符时不得下载 |
| 6 | `@font-face` 不带 `local()`；族名与系统字体同名也不会误用本地完整版 |
| 7 | 子集缺字允许逐字回退 `SimSun`（仍为衬线）；不改任何业务规则与文案 |
| 8 | 不改 `.mono` 的既有语义（部分表格 `td.mono` 仍走正文族），不动 30px 余额的 Inter 700 |
