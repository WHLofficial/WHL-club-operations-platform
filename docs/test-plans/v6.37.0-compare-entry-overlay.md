# 测试计划 · v6.37.0 球员对比浮层选人（compare-entry-overlay）

设计依据：`docs/superpowers/specs/2026-10-05-player-compare-design.md` v6.37.0 修订节（入口 B 交互形态：跳球员库 → 页内浮层）+ 定稿视觉稿（scratch/ui-mockup/compare-picker.html）。
执行层：vitest（web/src/pages/Player.test.tsx、PlayerCompare.test.tsx）+ e2e（scripts/e2e/smoke.mjs ⑤f）+ 变异验证。
基线：vitest 58 文件 / 964 例（v6.12.0 台账，含并行会话增量）。

## 范围

- **在范围内**：球员详情页「⇄ 加入对比」浮层（开/搜/选/满/移除/关/确认导航）；一人态「＋ 从球员库选」补 `?compare=`；`.player-card-compare` CSS 间距。
- **不在范围内**：球员库勾选流本身（TC-CMP-LIB-01…09 既有回归）、对比页 2/3 人态渲染、URL 直达降级。

## 用例

### TC-CMP-PICK-01 入口渲染与位置（P0，vitest）
前置：stub `/api/players/:id` 返回 detail(fcId=20801) 与 `/api/seasons/current`。
步骤/预期：① `.player-card-numbers` 的 nextElementSibling 是 `.player-card-compare`（位置契约，spec §0.10）；② 内含 `role=button` 名「⇄ 加入对比」（不再是 link）；③ detail(fcId=null) 时整块不渲染。
变异口径：位置断言拆掉应红。

### TC-CMP-PICK-02 开浮层初始态（P0，vitest）
步骤：点入口按钮。
预期：`role=dialog` 名「加入对比」出现；槽 A = 自己（文字为自己名）；两个「空位」；提示「再选 2 人即可开始对比」；计数「已选 1/3」；「开始对比」disabled；空查询候选区显「输入姓名搜索球员」。

### TC-CMP-PICK-03 搜索过滤与入槽（P0，vitest）
前置：stub `/api/players/roster`（blob 形状「姓名|俱乐部ID|fc_id」，含自由身无俱乐部段）与 `/api/clubs`（club id→名）。
步骤/预期：① 输入前缀 → 候选行出「姓名 + 球队名」（自由身显「自由身」）；② 点候选 → 入槽 B（第二个槽显其名）、行内 ✓、计数 2/3、提示「再选 1 人即可开始对比」、确认 enabled；③ 搜不到的词显「没有匹配…」。

### TC-CMP-PICK-04 确认导航（P0，vitest）
前置：测试 Routes 加 `/players/compare` 占位路由。
步骤：选 1 人后点「开始对比」。
预期：落 `/players/compare?ids=<own>,<picked>`——own 恒在首位（色 A 契约）。

### TC-CMP-PICK-05 上限与排除自己（P1，vitest）
步骤/预期：① 选满 2 人后其余候选行 disabled、提示「名额已满（含自己共 3 人）」；② 搜索自己的名字，候选里不出自己。
变异口径：拆掉 `picked.length >= 2` 拦截应红（③号变异）；拆掉 `fcId !== own.fcId` 过滤应红。

### TC-CMP-PICK-06 移除（P1，vitest）
步骤/预期：① 槽 ✕（aria-label「移除 X」）移除后空位恢复、计数回退、名额恢复；② 候选行再点（✓ 态）等效移除。

### TC-CMP-PICK-07 关闭三路（P1，vitest）
步骤/预期：Esc 关 / 点遮罩（面板外）关 / 点 ✕ 关；关闭后浮层自文档移除。

### TC-CMP-PICK-08 加载与错误态（P2，vitest）
步骤/预期：roster pending 显「名册加载中…」；roster reject 显「名册暂时拉不到，稍后再试」，页面不崩。

### TC-CMP-PICK-09 焦点（P2，vitest）
步骤/预期：① 开浮层后 document.activeElement 是关闭钮；② Esc 关闭后焦点回入口按钮。Tab 循环在真浏览器由 e2e 冒烟覆盖（jsdom 对 offsetParent 的表达有限）。

### TC-CMP-DET 回归（P0，vitest 改写）
原 TC-CMP-DET-01/02 改为 button 口径（并入 TC-CMP-PICK-01/02）；切页签入口常驻、fcId null 不渲染两条保持。

### TC-CMP-EMP-01 一人态回库补参（P0，vitest）
预期：`/players/compare?ids=<fcId>` 落 1 人态，「＋ 从球员库选」href = `/players?compare=<fcId>`（原 `/players`）；≥2 人态「编辑名单」href = `/players?compare=<ids>` 不变。

### e2e ⑤f 冒烟（P0）
- 1a 详情入口浮层链路：`/players/<A>` → 点 `.player-card-compare button` → `.cmp-picker-ov` 出现 → 搜索框填可命中字母 → 点首条 `.cmp-picker-item` → 「开始对比」→ `.cmp-page` 断言 2 人态（2 张 `.cmp-ids > .cmp-card`）。
- 1b 1 人态断言（cmp-emptyslot 虚线框 / 单人雷达 / 无对照表）改由 `goto /players/compare?ids=<A>` 直达保持。
- 2 人态 / 3 人态 / URL 直达降级子项不动。
