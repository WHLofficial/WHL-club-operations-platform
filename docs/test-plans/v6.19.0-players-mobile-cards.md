## 范围

**In scope**
- 纯函数：`attrClass` 五档边界 / `lensChips` 透镜口径 / `SORT_KEY_LABELS` 全集 / `money`。
- e2e：⑧ 球员库三视口——窄视口（900/375）渲染卡片列、宽视口（1280）tbody 原样、窄屏排序行、显示列窄屏隐藏。
- 回归：配色改动波及的面板属性页签 / 分组均值（经 attrClass 自动跟随，逻辑层由 TC-AC 承载）、桌面表格 CA/PA/初始 CA 列套色（e2e 宽视口类名断言）。

**Out of scope**
- 后端 / 迁移（零改动）；多 attr 筛选（后端单 attr 限制，spec §7 登记）；桌面布局与交互变化；浏览器兼容矩阵（沿用 e2e 单 Chrome 惯例）。

## 最坏情况口径（铁律）

- **attrClass 阈值将来最可能的重构 = 退回旧三档（50/70）**：变异 V1 必须让**恰好边界例**变红（50→mid 或 51→weak 之类），而不是随便哪例红。
- **lensChips 最可能被改坏的三处**：去重丢失、上限丢失、attr 优先级被降为并列——V2/V3/V4 各自定向红。
- **SORT_KEY_LABELS 漏键**：排序下拉出现 `undefined` 选项——用「覆盖 SORT_KEYS 全集」锁（TC-SKL-01），变异 V5 删一键必须红。
- **e2e 最大风险不是新断言而是旧断言**：⑧ 窄视口现有等待 `.library-main tbody tr` 在表格换卡片后必超时——适配本身是 P0 用例（TC-E2E-01）。
- **单测测最大组合**：lensChips 同轮命中「attr 筛选 + 排序键白名单 + 筛选维度白名单」三种来源 → attr 优先、其余被顶掉，最多 1 条（TC-LEN-08）。

## 用例

### TC-AC attrClass 五档分段（v6.19.0 全仓统一口径）

- **TC-AC-01 · 八个边界值各归对档**（P0 · vitest）：50→attr-bad、51→attr-weak、60→attr-weak、61→attr-mid、70→attr-mid、71→attr-solid、80→attr-solid、81→attr-good。前置：无。步骤：逐值断言返回类名。预期：逐格相等。
- **TC-AC-02 · 域端点与类名退役**（P1 · vitest）：0→attr-bad、99→attr-good；返回集合恰为 {attr-bad,attr-weak,attr-mid,attr-solid,attr-good}，不含 attr-low。理由：`attr-low` 退役（spec §5），防旧类名残留。

### TC-LEN lensChips 透镜口径（spec §3）

- **TC-LEN-01 · attr 筛选优先且单条**（P0 · vitest）：`filters.attr='dribbling'` + 排序键∈白名单 + 行 attrValue=79 → 仅 1 条 `{label:'盘带', raw:79, colored:true}`；白名单键不出现。
- **TC-LEN-02 · 排序键命中白名单**（P0 · vitest）：无 attr 筛选、`sort='prestige'` → 1 条声望（colored:false，声望 0-10 非 0-99 域）。
- **TC-LEN-03 · 筛选维度补位**（P1 · vitest）：排序键不在白名单（如 `sort='ca'`）+ 生效筛选含 `base_ca` 区间 → 补位 1 条初始 CA（**colored:true**，base_ca 属 0-99 域，spec §5）。
- **TC-LEN-04 · 排序键 + 筛选维度去重**（P0 · vitest）：`sort='wage'` + wage 筛选生效 → 仅 1 条 wage。
- **TC-LEN-05 · 上限 2 条**（P1 · vitest）：排序键 + 两个白名单筛选维度同时生效 → 恰 2 条（排序键优先序在前）。
- **TC-LEN-06 · 空集不渲染**（P1 · vitest）：无 attr、排序键不在白名单、无白名单筛选 → 返回空数组。
- **TC-LEN-07 · attrValue 缺失回退**（P1 · vitest）：attr 筛选在但行 `attrValue` 为 undefined → 该条 value 渲染 '—'（raw:null、colored:false）。
- **TC-LEN-08 · 三来源同击取 attr**（P0 · vitest）：attr 筛选 + 排序键∈白名单 + 筛选维度∈白名单 → 恰 1 条 attr。理由：最大组合，优先级语义。
- **TC-LEN-09 · growth_gap 不套色**（P2 · vitest）：透镜出成长空间（差值非 0-99 域）→ colored:false。

### TC-SKL / TC-MONEY 杂项纯函数

- **TC-SKL-01 · SORT_KEY_LABELS 覆盖 SORT_KEYS 全集**（P0 · vitest）：SORT_KEYS 每个键 label 均非空非 undefined；`id → '默认顺序'`。
- **TC-SKL-02 · attr 动态键拼接**（P1 · vitest）：`attr:dribbling → '属性·盘带'` 形态（走 ATTR_LABELS）。
- **TC-MONEY-01 · money(null) 与两位小数**（P1 · vitest）：null→'—'；1234→'1234.00 m'。
- **TC-MONEY-02 · 行为不回归**（P2 · vitest）：money(0)→'0.00 m'（0 是有效值非 null）。

### TC-E2E e2e ⑧ 三视口适配（scripts/e2e/smoke.mjs）

- **TC-E2E-01 · 窄视口渲染卡片列**（P0 · e2e）：900×800 与 375×812 下等待 `.lib-cards .lib-card`（替换原 tbody 等待），首卡含 CA/PA 数值与姓名文本、卡数 >0；`.library-main table` 不存在。
- **TC-E2E-02 · 宽视口 tbody 原样**（P0 · e2e）：1280×900 下仍等 tbody tr、`.lib-cards` 不存在；CA/PA 表头排序点击不受影响。
- **TC-E2E-03 · 窄屏排序行**（P1 · e2e）：窄视口 `.lib-sortrow` 可见，select 换键后 URL `sort=` 变化且卡片列仍在；宽视口 `.lib-sortrow` 不存在。
- **TC-E2E-04 · 显示列窄屏隐藏**（P2 · e2e）：窄视口 `.lib-chip-row`（显示列 MultiSelect 所在）不可见；宽视口可见。
