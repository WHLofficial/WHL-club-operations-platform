## 范围

**In**：①录入台列表按「赛事 → 轮次」分组（`groupMatchEntries`、列表/面板端点补 `tournamentId/tournamentName`）；②停赛球员硬拦截（`src/worker/tour-suspension.ts` 复算赛事仓停赛引擎：直红/两黄变一红/累积黄牌，含两遍锚点重放；面板逐人下发 `suspended`、批量与单条端点 400 拒收、前端整行锁定）；③出场记录不再走赛果自动通道（改由截图识别 + 人工在录入台补录）；④训练营球员与正式球员同口径按场次记 XP（录入侧与自动通道两侧闸门同时移除，赛季结算 `trainee_season` 固定 XP 保留）。
**Out**：伤停（injury）拦截、停赛规则本身（阈值/停赛场次配置的编辑入口）、赛季结算数值、跨仓 HTTP 调用（club 侧只读 TOUR_DB 复算，不新增接口）、把 club 侧镜像合并回赛事仓。

## 最坏情况口径（铁律）

- 判不出停赛（`players.fc_id` 为空、比赛不在赛事序列里、赛事库读不到该球员卡片）→ **放行**，绝不误锁：误锁会让人少录一场 XP，误放行有补录与人工复核兜底。
- 跨库查询失败（TOUR_DB 报错）→ 不吞异常：面板/补录整体 500，宁可录不了也不放行停赛球员。
- 同一场既消耗旧停赛又触发新停赛 → **先消耗后触发**（与赛事仓 `replay` 同序）；pending 比赛既不消耗也不算刑期；弃权方不消耗（双方弃权都不消耗）。
- 两黄变一红：同场那张黄牌不计入累积；累积黄牌达阈值触发停赛后黄牌清零。
- 黄牌锚点（`yellowResetAt`）只重置黄牌累积，红牌停赛照常消耗（两遍重放：锚点前段正常消耗、锚点后段接力不重复消耗）。
- 出场去自动化不伤及进球/助攻/零封：自动通道只删 `appearance` 一条支路。
- 训练营放开只放开「按场次」：赛季结算那条线（`trainee_season`，40/15）一分不动。

## 变异验证（≥6 处，按将来最可能的重构方式弄坏）

1. `replayCapture` 的消耗条件去掉 `b.from <= i`（同场新停赛立刻消耗）→ TC-SUS-01/06 红。
2. 黄牌触发判定 `>= threshold` 改 `> threshold` → TC-SUS-05/12 红。
3. 弃权判定去掉 `wo === 'both'` 分支 → TC-SUS-07 红。
4. 面板 `suspended` 映射改成常量 `null`（不再查引擎）→ TC-PANEL-04 红。
5. 批量端点 `if (s)` 守卫删除 → TC-BATCH-03 红。
6. `groupMatchEntries` 组键去掉赛事前缀（`${m.round}|${stageName}`）→ TC-GRP-02 红。
7. `results.ts` 恢复自动出场 push → growth/results 两处「无 appearance」断言红。
