# 测试计划 · v6.60.8 挂牌卡队徽 / 领先买家 / 浮层首开 / CA-PA 配色

> 按 qa-test-planner 约定设计。执行层 = vitest（组件 + CSS 文本锁 + 详情端点）+ 本地真栈手测（浮层首开体感、窄屏排布）。
> 设计依据：用户口径「修复转会区卡片队徽显示回退到色块+首字」「修复剩余时间右边显示的不是当前领先买家」「点击挂牌卡浮层首次开启慢」「挂牌卡的 CA/PA 要对齐五档配色方案」；术语见 `GLOSSARY.md`「队徽 / 领先出价」。

## 一、范围与目标

**In scope**：

1. `/market` 在售市场卡片的卖方队徽、卡脚领先买家家徽、详情浮层的卖方徽与出价历史徽，一律走比赛系统 `team.logo_key`（经 `GET /api/clubs` 目录折成 `club_id → logoKey`），不再回落「队名哈希色块 + 首字」。
2. 卡片卡脚右侧由卖方队名改为**当前领先买家**（`highestBidder`）；无人出价给「无人领先」占位。
3. 浮层首开提速：卡片被指向 / 按下 / 聚焦时预取详情；详情端点内部 D1 往返从四趟降到两趟。
4. 挂牌卡 CA/PA 重新按五档配色（`attr-bad|weak|mid|solid|good`）。

**Out of scope**：`/api/clubs` 服务端队徽折叠逻辑本身（`src/worker/club-logos.ts`）、`TeamLogo` 回落色板、市场结算与出价校验规则、`clubs.logo_key` 休眠列是否启用、移动端原生 hover 行为。

## 三、用例

### A. 队徽不回落（TC-L）

**TC-L-001 · 卡片与卡脚队徽出真图（P0）**

前置：页面传入 `logoOf` 映射（club 3、4 都有 `logoKey`）。
步骤：渲染 `MarketCard`。
预期：① 两枚 `img[role="img"]` 的 `src` 分别是 `/api/media/club-3.png`、`/api/media/club-4.png`；② `.team-logo-fallback` 数量为 0。

**TC-L-002 · 目录未命中仍回落（P0）**

前置：`logoOf` 对任意 club_id 返回 `null`。
步骤：渲染 `MarketCard`。
预期：① 不渲染任何 `img`；② `.team-logo-fallback` 数量为 2（买方徽改用领先买家家徽后仍是两枚）；③ 不抛错、不空占位。

**TC-L-003 · 浮层卖方徽与出价历史徽同源（P1）**

前置：打开 `MarketListingOverlay`（传 `logoOf`）。
步骤：看「卖方」行与出价历史「出价方」列。
预期：① 两处 `TeamLogo` 都带 `logoKey`；② 出价行的键来自 `bid.clubId`，与卡片口径一致；③ 不传 `logoOf` 时行为与改造前完全相同（回落色块）。

### B. 卡脚右侧 = 当前领先买家（TC-B）

**TC-B-001 · 有领先出价（P0）**

前置：`highestBidder` 非空。
步骤：渲染卡片。
预期：① 卡脚右侧出现「领先」标签 + 买家队徽 + 买家队名；② `title` 为「当前领先：<买家>」；③ 卖方队名**不**出现在卡脚（只在卡头徽与浮层里出现）。

**TC-B-002 · 无人出价（P0）**

前置：`highestBidder === null`。
步骤：渲染卡片。
预期：① 显示「无人领先」；② 不显示「领先」标签、不渲染买家徽；③ 倒计时仍在卡脚左侧。

**TC-B-003 · 窄屏不折行、不压掉倒计时（P1）**

步骤：375×812 打开 `/market`（或手测 DevTools 视口）。
预期：① `.mkt-timer` 与 `.mkt-tn` 同排；② 长队名走 ellipsis 截断，不换行、不撑出卡片；③ 「无人领先」不折成两行。

### C. 浮层首开提速（TC-C）

**TC-C-001 · 指向 / 按下 / 聚焦各触发一次预取（P0）**

前置：`onPrefetch` 用 spy。
步骤：对卡片分别 `pointerOver` / `pointerDown` / `focus`。
预期：① spy 调用 3 次；② `click` 只让 `onOpen` 调 1 次，不额外触发预取；③ 预取与打开互不阻塞。

**TC-C-002 · 只预取被指向过的卡片（P1）**

步骤：同屏 20 张卡，只 hover 其中一张。
预期：① 只发出 1 条 `/api/market/listings/:id`；② 30s 内重复 hover 不重取（沿用全局 staleTime）。

**TC-C-003 · 详情端点形状与最低出价不变（P0）**

前置：并行化改造（`MAX(amount)` 与 `market_bid_paused` 并进首个 `Promise.all`）。
步骤：`GET /api/market/listings/:id`。
预期：① `marketBidPaused` 仍读 `market_bid_paused` 配置（`'true'` 才为 true）；② `nextMinBid` 仍为 ceil(最高活跃价 + 步长)，无出价时 ceil(挂牌价)；③ 不存在的 ID 仍 404、非整数 ID 仍 400。

### D. CA/PA 五档配色（TC-D）

**TC-D-001 · 层叠顺序锁（P0）**

步骤：读 `web/src/styles.css` 文本。
预期：① `.mkt-rail-num.attr-bad|weak|mid|solid|good` 五条覆盖规则都存在且 color 指向对应 `--attr-*`；② 五条的 `indexOf` 都大于 `.mkt-rail-num {` 基规则位置。

**TC-D-002 · 真机颜色（P1）**

步骤：`/market` 看 CA/PA 数字。
预期：① CA 51 走弱档橙、PA 82 走优档绿（阈值 50/60/70/80 见 `web/src/lib/players-library.ts`）；② 无值「—」仍墨色，不被档位色覆盖；③ 暗色主题下同排文字对比度仍可读。
