# 测试计划 · v6.54.1 转会价格口径三缺陷修复

日期：2026-10-26 · 类型：缺陷修复（校验口径对齐 + 取整 + 层级）· 零迁移零生产写。
对应计划：`memory/plan-v6.54.1-transfer-price-bounds.md`。

## 范围

**测**：① `setOfferSettings` 标价换 `listingPriceBounds`（下限 = max(1, ⌈min(0.5×违约金, 0.5×身价)⌉)）；② 两边界函数取整（下限 ceil / 上限 floor）与前端 `offerCap` 同步；③ `.toast` z-index 950 高于浮层 900。
**不测**：最低报价下限仍 1（口径未动）；手工同意/名单外自动同意的低于下限成交路径（登记未修，另令）；挂牌要价小数输入（未动）。
