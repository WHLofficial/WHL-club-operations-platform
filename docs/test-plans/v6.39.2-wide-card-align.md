# v6.39.2 测试计划 · 桌面球队页宽卡列对齐（+ 注册台列集 11 列 + 金额单位紧贴数字）

**范围**：`web/src/pages/club/card-parts.tsx`（CardGroup 列头共用列表、RegCard 切 11 列集）、`web/src/styles.css`（`.sqc-glegend` 网格 + `.sqc-group.wide` 几何 token 块 + `.sqc-card.wide` 值区轨网格/数值 nowrap/分配列定宽）、`web/src/pages/club/DeskTab.tsx`（CardGroup 传 `assign`、切 11 列集）、`web/src/lib/club-cards.ts`（新增 `DESKTOP_CELLS_DESK`）、金额单位「m」紧贴数字的前端 sweep（`web/src/**` 143 处 + `scripts/e2e/smoke.mjs`）。零迁移、零生产写、无 API 契约变更。

**缘起**：用户令 m03731（v6.39.1 收尾途中）「表头和数据不对齐；名字列宽度太低，且与后面数据距离太近」——桌面 `/clubs/:id?tab=squad` 同一屏。**同版追加两条用户裁决**（实施途中实时提出）：① 注册工作台桌面列 13→11（舍「初始CA」「成长空间」，以放下所有列在一行）② 金额单位 m 紧贴数字（「150.00 m」→「150.00m」，理由「观感割裂」）。

**不变量（本版必须守住）**：
1. 列头与值区**逐列右缘对齐**（同一套 `repeat(auto-fit, minmax(var(--sqc-wmin, 58px), 1fr))` + `gap: 4px var(--sqc-wgap, 6px)`），宽度差 ≤2px；
2. 身份列 210px、列距 22px（token 唯一出处 `.sqc-group.wide`）；
3. 窄屏卡形态（`:not(.wide)`）零回归——两行式、75% 右对齐值区、徽章跟名同行；
4. 桌面两个使用点（阵容 / 注册名单）同修，`.has-assign` 在注册名单列头右侧让出 `--sqc-assignw + --sqc-cgap`；
5. 阵容页签 13 列（`DESKTOP_CELLS`）、注册工作台 11 列（`DESKTOP_CELLS_DESK`）——两处列集**不得互串**；注册台值区 @1280 单行。

## 七、注意事项

1. **改源码后必须先 `npm run build` 再跑探针 / e2e**：`npm run dev` 是 `wrangler dev` 服务 `vite build` 后的 `dist/` 静态产物，无 HMR（本版首次探针跑出旧值 `idW 170 / cgap 14 / flex` 白跑一轮；另一次 build 跑在补 import 之前，导致 e2e ⑪ 捕获 `DESKTOP_CELLS_DESK is not defined` 的 stale bundle）。
2. e2e 依赖本地 dev 在 `http://127.0.0.1:8791`（health=200）；dev 未起时 24 项会全红 `ERR_CONNECTION_REFUSED`（非断言失败）。本版中途 dev 曾停（经代理 curl 得 502、`--noproxy` 得 000、netstat 无监听）⇒ `nohup npm run dev` 重启，约 3s 就绪。
3. 探针必须放仓内 `scratch/`（仓外目录 `import playwright-core` 解析失败）；`__Host-club_session` cookie 必须写 `domain + path + secure + sameSite`（用 `url` 注入报 `Invalid cookie fields`）。
4. 同类隐患（登记不改）：`web/src/pages/PlayersLibrary.tsx:53` 球员库走独立机制（lib-card/表、断点 900 与主机制 760 不一致）；宽窄判定走 `matchMedia` viewport 而非容器查询（宽视口 + 窄容器会误拿 wide，当前两处皆全宽不触发）。
5. **判断命令退出码别走管道**：`npm run typecheck 2>&1 | tail` 的 `$?` 是 `tail` 的 ⇒ 本版曾把一份含 TS2552 的输出读成 `EXIT=0`（后改用不带管道直接取 `$?`，并把顺序固定为 typecheck → build → e2e）。
6. **金额单位 sweep 范围**：只改前端（`web/src/**` + `scripts/e2e/smoke.mjs`），**`src/**`（worker/core）文案不动**——`src/worker/window-payroll.ts` 的 memo「未达顶级下限 53 m，按下限扣」是生产订正批 `scripts/prod-20261006-s9-wage-floor-fix/` 的核对串、且被 `tests/season-settle.test.ts:291-292` 断言，动它会牵动该批与约 35 条后端断言。应用后残留检查（`grep -rnE '(\d|[})]) m([^a-zA-Z]|$)' web/src` 与 `grep -rn "' m'"`）均为空。
