## 一、不变量

1. `/api/players` 每行恒有 `clubLogoKey`：自由身（`club_id IS NULL`）恒 `null`；有归属则「有映射且有 `logo_key`」给键，其余 `null`。
2. 前端宽屏球队格 = 徽 + 队名的链接（`a.lib-club`），自由身不给链接、不给徽（纯文本「自由身」）。
3. 窄屏铭牌卡所属球队行必须传 `logoKey`（不传 = 静默降级成哈希色块，正是本版修掉的老形态）。
4. 映射只有一份实现：`/api/players` 与 `/api/clubs` 都从 `src/worker/club-logos.ts` 取，`routes/clubs.ts` 不留本地副本。
5. 徽与队名并存（徽是前置缩略图，不替代文字）——e2e 断言 `.lib-club` 文本仍含队名。

## 九、注意事项

1. 本地 dev（8791）服务 `dist/` ⇒ 改源码后必须 `npm run build` 才生效（否则跑出旧值）。
2. `wrangler dev` 启动瞬间会短暂 404（build 写 dist 的竞态），复探即 200。
3. 加必填字段的连锁面：所有 `PlayerLibraryRow` 行夹具都要补 `clubLogoKey`；typecheck 是唯一一次抓全的闸门。
4. `TeamLogo` 自带哈希色块 fallback ⇒ 「看起来没坏」不等于「logoKey 传下去了」；断言要落在传递链上。
