**最坏情况口径**
| 假设坏了 | 表现 | 兜底 |
| --- | --- | --- |
| 形态层过宽（同姓两人被判同一人） | 认错球员 ⇒ 评分录到别人身上 | 只认「全队列唯一命中」，多命中回 null（TC-MATCH-04 末例）；且库内同队同姓并存时也会落回不猜 |
| 形态层过窄（该认的没认） | 仍报「认人失败」，人工下拉指定 | 与改动前一致，不劣化 |
| 思考字段被端点拒绝 | 视觉调用 502「LLM 返回 400」 | `LLM_VISION_THINKING=on` 去掉该字段；`glm-4v-flash`/`glm-4.6v-flashx` 都实测接受（HTTP 200）；非智谱端点本就不带 |
| 关思考后识别变差 | 名单缺行/读错名 | 4 张真图关/开思考逐条一致；漏行会被 `finish_reason=length` 与交叉校验拦下；必要时 `LLM_VISION_THINKING=on` 回退 |
| `discardDrafts` 用到过期 data | 丢弃后填回旧值 | 丢弃只重建空行（用当前 query data 建基线行），不写库；此后合并/保存才写 |
