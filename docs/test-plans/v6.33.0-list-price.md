## 7. code-review 处置（2026-10-05）

**结论：无阻塞项（P0 0 / P1 0）** —— 逐 hunk 复核后端（`offer-rules.ts` / `offers.ts` / `routes/{offers,players,market}.ts` / `notify.ts` / 迁移 0065）+ 前端（`SideOps.tsx` / `MarketAdBoardPage.tsx` / `OffersSection.tsx` / `styles.css`）+ 全部测试改动。核过并确认无误的点：

- **校验先于副作用**：`setOfferSettings` 的「标价 < 最低报价」400 排在 `db.batch` 与「置非卖品批量拒」之前（`src/worker/offers.ts:896-975` 段），400 时零落库；非卖品批量拒的既有语义未动。
- **私密面收口**：`min_offer_price` 全仓只剩私密路径（`src/core/offer-rules.ts` 形参名、`src/worker/offers.ts` 内部判定、`src/worker/routes/offers.ts` 的 GET/PUT offer-settings）；审计 `after` 只落布尔 + 公开数值且该调用无 `before` 键；新端点 `GET /api/players/:id/offer-settings` 守卫链与 PUT 同源（匿名 401 / 非本队 404 / 挂牌 409）。
- **不变量无旁路**：`transfer_listed` 全仓唯一写点是 `src/worker/offers.ts:918` ⇒「list_price 非空 ⇒ 名单内」不被其他路径破坏；`OFFER_WITH_CONTEXT`（`src/worker/offers.ts:66`）里的 `min_offer_price` 是既有惰性取列、无消费点。
- **缓存代际键**：`src/lib/guard.ts:215-218` 键形 `${scope}:v${epoch}:${key}` ⇒ 发布轮 bump KV `cache:epoch:public` 即清旧形状（transfer-board 与球员详情同源，无需逐键清）。

**登记不改（评审新增三条）**：① 标价/最低价输入框只滤字符，`1.2.3` 这类 `Number()` → NaN 的草稿经 JSON 变 null —— 标价会被「进名单必填」400 拦住，最低价则静默清空（与 v6.4.0 起既有数值输入同模式，服务端兜底）；② 广告板行 `listPrice` 为 null 时弹层文案会渲染「对方标价 —：…」（迁移回填后生产无此态，代码显式支持该态，仅文案观感）；③ `AdBidModal` 不响应 Escape（遮罩点击 + 取消按钮已在；`PromptDialog` 是全仓唯一带 Escape 的弹层，不做单点追齐）。
