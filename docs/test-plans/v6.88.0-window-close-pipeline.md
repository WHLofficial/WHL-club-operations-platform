### T02 · claim 批 SQL 幂等：失败不重建 run、closed 不复活（P0）

### T03 · 业务校验全在 claim 之前：失败零 run 行、窗口保持 open（P0）

- **操作/断言**（共同尾断言：`season_windows(1,1)` 仍 'open'、`window_close_runs` 与 `window_close_steps` 均 0 行——「校验失败不 claim」）：
