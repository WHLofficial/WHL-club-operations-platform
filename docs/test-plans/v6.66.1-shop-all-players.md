# 测试计划 · v6.66.1 消费中心对本队全部球员开放（含训练营）

## 背景与范围

owner 诉求（m01103）：「希望消费中心中可以给本队所有球员做操作，不局限于一线队人员。」只读查证结论：服务端各品类守卫与 `loadPlayer` 只校验 `club_id`、不看 status（`src/worker/shop-ops.ts:170-177`、`:294-300`/`:316`/`:400`/`:468`/`:553`），训练营球员今天直接提交工单就能过；真正挡住的是 `GET /api/shop/squad-state` 的唯一 status 白名单（`src/worker/routes/shop.ts:36-41`），以及 DTO 不带 status 导致前端无法分组。

**In scope**：squad-state 候选改裸 `club_id = ?`、行与 DTO 补 `status`、`PlayerSelect` 按 status 分三组（一线队 / 训练营 / 挂牌中，未知落「其他」）。
**Out of scope**：合同类型校验（明确不做）、管理端工单标记、`squads.ts` 注册口径、价格与资金链路、审批语义（`prepareShopPlan` 重跑零改动）。

## 用例

### TC-S1 三状态齐出且 status 正确（P0，变异锚）

**前置**：俱乐部 101 绑定教练；球员 1 `status=normal`、2 `listed`、3 `trainee`，均 `club_id=101`。
**步骤**：GET `/api/shop/squad-state`（教练会话）。
**预期**：200；`players` 恰含 id 1/2/3，`status` 分别为 `normal` / `listed` / `trainee`；训练营球员在列（v6.66.1 前缺失）。
**变异锚**：M1（SQL 回白名单）⇒ 本例红。

### TC-S2 排除他队与无队球员（P0）

**前置**：球员 4 `club_id=102`（他队）、5 `club_id=NULL`。
**预期**：squad-state 的 `players` 不含 4/5；`clubId` 仍为 101。

### TC-S3 训练营 PA 工单闭环（P0，变异锚）

**前置**：用例单独建夹具，只 seed 一名球员（`seedPlayer` 的 id 参数写 `fc_id`、主键自增，故该夹具主键为 **1**）`status=trainee`、`growable=1`、`pa=88`；窗开、运营时段默认放行。
**步骤**：`POST /api/shop/orders` `{ category:'pa', payload:{ playerId:1, points:2 } }` → 201 pending；管理端 approve。
**预期**：提交 201 且扣费；审批 200；`players.pa` 88 → 90。
**变异锚**：M4（`loadPlayer` 加 status 白名单）⇒ 本例红。

### TC-S4 训练营徽章工单闭环（P1）

**前置**：单独夹具只 seed 一名 `status=trainee` 球员（主键 1）。
**步骤**：提交 `{ category:'badge', payload:{ playerId:1, kind:'gold', psid:5 } }` → approve。
**预期**：201 / 200；`player_playstyles` 落 `kind='gold', psid=5, source='shop'`。

### TC-R1 PA 卡 `growable` 过滤不受影响（P1，回归）

**前置**：badge 页签有 normal + trainee + listed 三类球员；PA 页签另有 `growable=false` 的 trainee。
**预期**：徽章卡下拉三类齐出；PA 卡下拉只剩 `growable=true`（不可成长球员仍被挡，分组不改变过滤语义）。

### TC-W1 optgroup 分组与兜底（P0，变异锚）

**前置**：squad-state mock：id 6 normal「一线前锋」`#9`、7 trainee「青训小将」（无号码）、8 listed「挂牌中场」`#5`、9 未知状态 `loan`「外租球员」；打开 `/shop?tab=badge`。
**预期**：球员下拉的 `optgroup` 依次为「一线队」「训练营」「挂牌中」「其他」；前三组各含对应 id，未知状态球员落「其他」不丢人；option 文本仍是 `#号 姓名`（无号码者只有姓名）；占位项「选球员…」不在任何组内。
**变异锚**：M2（DTO 去 status）/ M3（分组恒一线队）⇒ 本例红。

### TC-W2 空组不渲染 + 训练营提交 body（P0，变异锚）

**前置**：squad-state 只有一名 trainee「青训小将」id 7 `growable=true`；打开 `/shop?tab=pa`（PA 卡 `growable` 过滤后仍剩它）。
**预期**：下拉只有一个 `optgroup`「训练营」，不出现空的「一线队」「挂牌中」；选中 7、点数 1、确认后 `apiPost('/api/shop/orders', { category:'pa', payload:{ playerId:7, points:1 }, note:null })`。
**变异锚**：M5（`PlayerSelect` 丢训练营组）⇒ 本例红。

### TC-W3 其他兜底不吞人（P2）

**前置**：squad-state 只有未知状态球员（`status='loan'`）。
**预期**：下拉只有「其他」组且含该球员，不会被空组或白名单静默丢掉。
