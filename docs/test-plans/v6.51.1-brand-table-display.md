## 范围与风险

**In**：桌面表格列序与列数；「总部」列只读性（无 `input` / `select` / `textarea`）；「来源 / 状态」两列的类名与样式规则本体（字号 + 禁折）在位；固定宽禁令白名单双向核对（新字面量登记、旧字面量零残留）；收窄后列内容不破版。

**Out**：品牌档案 / 招商性格区默认收起（随 v6.51.0 已上线，本版不动）；后端校验（`tests/naming-brand-profile.test.ts` 已覆盖）；像素级视觉走查（人工验收覆盖）；窄屏（≤760）卡片流的截图比对。

**最坏情况口径**：
- **规则被写进行内样式**：若把 `font-size` / `white-space` 内联到 `<td>` 上，静态锁（TC-BR-04）与固定宽禁令双向核对（TC-SWP-02）会同时失效，且日后调样式要改 JSX。闸门 = 规则只落 `web/src/styles.css`，行内仅保留动态值（品牌色块的 `background`）；TC-BR-04 的末段静态锁直接读 `styles.css` 匹配 `/\.brand-meta-cell\s*\{[^}]*font-size:\s*12px;[^}]*white-space:\s*nowrap;/`。
- **「总部」被做成可编辑控件**：用户明确「仅展示列」，做成输入框会让同一字段出现两个编辑入口（档案网格里已有「总部」输入）。闸门 = TC-BR-04 断言 `cells[1]` 内 `input, select, textarea` 为 `null`，且文本恰等于该行 `hq`。
- **新增固定宽未登记 ⇒ 静态闸门红**：`tests/mobile-baseline.test.ts` 的 `FIXED_WIDTH_ALLOWLIST` 要求条目恰好命中 1 次、清单外零命中。闸门 = 两条字面量同步改（`96` → `72`、`72` → `56`）并在 `why` 里写明 v6.51.1 收窄理由。
- **收窄后值被截断**：热度值形如 `0.95`（4 字符）、行业值恒为 2 个汉字，按 12px 字号估算远小于 56px / 72px 输入宽。未做像素级断言，靠浏览器实测登记兜底（见下）。
