# v6.60.10 测试计划 · 强制挂牌置顶与「强拍」徽标

起因（用户口径）：「强制挂牌在转会区始终排在最前」。同轮另有生产 `config` 回调（编制 30 / 训练营 7 / 成长名额 6），那是数据改动，验收见 `scripts/prod-20261030-squad-limits-revert/README.md`。

范围：`GET /api/market/listings` 的排序 + `/market`（在售市场）卡片的卡头徽标。

## 自动化已覆盖

| 用例 | 断言 | 落点 |
| --- | --- | --- |
| 混排置顶 | 两条强拍（id 2、4）+ 两条普通（id 1、3）→ 取序 `[4,2,3,1]` | `tests/market-listing-order.test.ts` |
| 强拍优先于新旧 | 强拍 id 更小仍排最前 → `[1,9,5]` | 同上 |
| 状态口径一致 | `status=all` 与 `status=active` 排序口径相同 | 同上 |
| 卡头徽标 | `type='forced'` 出「强拍」；`normal` / `activation` 都不出 | `web/src/pages/market/MarketCard.test.tsx` |

## 手工回归（管理端 + 市场页）

| 编号 | 前置 | 判据 |
| --- | --- | --- |
| TC-FL-01 | 管理端对任一球员发起强制拍卖（`listings.type='forced'`），市场页已有多条普通挂牌 | `/market` 卡柜第一条就是这单强拍，且卡头有红色「强拍」徽标 |

| TC-FL-03 | 两条强拍先后挂出 | 两条都在最前区，彼此按新旧倒序（新的在前） |
| TC-FL-04 | 点开强拍卡片 | 浮层「卖方」行正常，竞价状态徽标仍按 `listingBadge()` 显示（强拍单不额外标「强拍」，与卡头刻意不同） |
| TC-FL-05 | 强拍单到期结算 / 被取消后 | 退回普通排序队列，徽标消失，卡柜不再置顶 |
| TC-FL-06 | 管理端市场页（`web/src/pages/admin/MarketPage.tsx`） | 该页一次取当前挂牌表，排序变化不影响其展示与操作按钮 |
