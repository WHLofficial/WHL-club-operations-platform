## 背景与范围

**改动 1（分流豁免撤销）**：`settleByContractType`（`src/worker/market-settle.ts`）撤掉「被激活方是训练营合同 → 竞价截止直进待审」的豁免。激活挂牌竞价截止后**一律**进 `matched_pending`（24h 匹配窗，基准 = 竞价最高价）。用户裁决依据：匹配成约必然是正式合同（`chooseTrainee` 拒收 match 型过户，negotiations.ts），所以「匹配之后为正式合同、只能进一线队」自动成立；无人匹配到期按竞价最高价成交进待审，同样走既有 `settleListingForReview`。

**改动 2（死线堵漏）**：`bidDeadline`（`src/core/market-rules.ts`）判定日**跳过出价当日**。出价发生在 X 日 ⇒ 最早判定日 X+1（交易日），死线恒为下一交易日 21:00（默认口径 silence 3h + 窗 18:00-23:00）。堵掉「X 日 18:00-20:59 出价、当日 21:00 就截止」的现象。存量已落库的 `deadline_at` 不回改——只影响未来出价推进。

**文案（2 处）**：`MarketActivationPage.tsx` / `MarketListingOverlay.tsx` 的「训练营直进待审 / 直进管理组审核」口径订正；`activations.ts` / `market-settle.ts` 两处源码头注释同步。

**不改动**：正式合同激活路径（matched_pending 既有机制）、匹配/放行/到期结算、交易日历顺延、强制拍卖 minOffsetDays=2、无出价挂牌的判定起点。
