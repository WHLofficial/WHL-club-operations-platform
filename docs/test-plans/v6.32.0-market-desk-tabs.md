# 测试计划 · v6.32.0 转会台页签化 + 市场域信息架构重排

> qa-test-planner 设计（2026-10-05）。执行层：vitest（web jsdom + 静态扫描）、e2e smoke、变异验证。
> 同版本范围：本计划只覆盖转会台与市场域 IA；工作区另一会话的广告板后续改动不在本计划内。

## 1. 目标与口径

- `/market/desk` 从三区块同屏长滚动页改为真页签（`.seg.dossier-tabs` + 条件挂载 + 按需取数），页签自带计数，删待办速览条与滚动对齐机制。
- IA 去重：删转会台「已落定的谈判」表（历史归 `/clubs/:id?tab=transfers` 队史）；报价页签改名「报价」（box in/out 次级切换保留）；流水线说明条精简一行。
- 清理：money() 三份实现收口到 shared；删死类名 `.row-open`；NegotiationsSection 魔数具名；`useMyNegotiations` 挪 `lib/queries.ts`。
- 判级 minor：纯前端信息架构 + 清理，零迁移、零后端改动、零新 CSS。

## 2. 范围

**In**：`MarketDeskPage.tsx`、`desk/NegotiationsSection.tsx`、`desk/OffersSection.tsx`、`lib/queries.ts`（收编 hook）、`scripts/e2e/smoke.mjs` ⑤c、`tests/mobile-baseline.test.ts` 结构守卫与表格基线、新增 `MarketDeskPage.test.tsx`。
**Out**：OfferDesk / SessionCard / 出价表单等区块内部交互；`shared.tsx` MarketNav；后端全部；intel/board/free/activation 页；另一会话在改的 `styles.css`、`MarketAdBoardPage.tsx`、`src/worker/routes/market.ts`。

## 3. 夹具基准（沿用 e2e stubDesk 数据）

谈判 3 会话 = 2 active + 1 settled（前锋丁）；报价 in 3 条（pendingMine=1，含 1 条 accepted）+ out 1 条（pendingMine=0）；出价 3 条 = 1 active + 1 won+待审核 + 1 won+settled。
**注意**：现网夹具 out 侧 pendingMine=0，「报价计数 = in+out 两盒之和」这个不变量在 e2e 夹具下不可分辨（变异 M3 会空转）⇒ 该不变量由 web 单测夹具锁（out pendingMine=2）。
