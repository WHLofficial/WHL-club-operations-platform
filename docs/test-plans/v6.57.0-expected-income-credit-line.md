## 最坏情况与变异
- 触发器 fail-open（config 方向）：缺行必须按 1.0、'abc'/''/'-1' 按 0，两层一致——裸 CAST 缺行时整式 NULL、RAISE 不触发（本机实测 500 放行），TC-B-011/012。
