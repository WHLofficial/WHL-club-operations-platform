## 6. 已知边界（登记不改）

- 台账派生语义依赖「先 apply 0086 再 push」的上线顺序；顺序颠倒时任何一次明细变更的重算都会重新对齐，最终一致。
- `?ps=` 银值 NOT EXISTS 只在槽命中行求值（AND 短路）；读量实测预期与现状持平（现状即 SCAN 豁免形状）。
- meta 的 granted source 归组硬编码 'growth'（meta 输出不含 source，仅合并逻辑内部使用）。
- 管理端直发（source='manual'）无独立端点——修正通道 = china 端点 / 商店 external 代录。
