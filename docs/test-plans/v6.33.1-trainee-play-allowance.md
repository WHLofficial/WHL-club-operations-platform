## 范围

**In scope**

- A1 名册开关 `squads_include_trainee`：GET /api/squads 默认只出一线队（`status IN ('normal','listed')`）；置 'true' 后训练营随队下发、每行带 `squad`（first_team/trainee）；**开关值已并进缓存键**（`squads:all:${includeTrainee}`）⇒ 翻转后最坏陈旧＝config 记忆化 ≤60s（记忆化一过期即换键重算），写路径代际 purge 只是让换键提前、24h TTL 只是键不变时的兜底（不再有「旧口径写进新代际键、24h 伺服旧口径」的窗口）。
- A2 注册校验放行档 `registration_check_mode` 三态：enforce（默认，不合规 422 且不落库）/ warn（放行落库、响应带 issues、审计记档）/ off（放行、工作台不挂红字）；脏值回落 enforce；只作用于教练侧（工作台 + 提交），管理端扫描不受影响。
- A3 回滚口径：两键回默认（或 `value=null` 删覆盖）后行为回到平常。
- B 全员注册生产脚本批（待执行）：precheck → 先开 `squads_include_trainee` → 写批（约 570 行 registrations + 69 人 status='trainee'）→ verify 回读 → 回滚脚本；含 CPU 两队口径、四冲突队 config 豁免、期后回滚四键。
- C 顶栏改名（待执行）：`球队中心→我的球队`、`球队→球队库` + 其余 12 处同名文案是否统一；无残留旧词。

**Out of scope**

- 赛事仓（clubRoster.ts / lineup.ts）自身改造：只做只读核对（TC-SQ-07）与生产回读（TC-SQ-06）。
- 球员对比、tour 改动、push / 上线动作本身。
- CSV 核对新发现的 164 名非平台球员（布鲁日 28 / 国际米兰 26 / 牛津联 37 / 在解约 73）——待拍，与本次注册批无依赖。
- CPU 两队合同缺口（53 人）与 AC米兰 CSV 标出的 2 名训练营球员的补合同——另作独立事项。

## 最坏情况口径（铁律）

- **坏值绝不意外放行**：`squads_include_trainee` 只在值恰为 `'true'` 时含训练营；`registration_check_mode` 白名单只认 `warn`/`off`，缺值/脏值/大小写变体一律回落 `enforce` → TC-SQ-04、TC-MODE-04/05。
- **放行不等于关闭体检**：warn/off 只放行、不改计算——一线队人数、门将数、训练营人数、训练营资格（可成长且 PA−CA>0）、CA/PA 梯度、现行合同、工资帽这 7 条照算并回 `issues`（前端按档位决定挂不挂红字），提交审计 after 记下当时档位与未过规则名清单；管理端 `/api/admin/compliance` 永远算真实体检 → TC-MODE-02/03/06/08。
- **对外契约加字段安全**：赛事侧解析只挑 `fcId/name/number`，`squad` 是新增字段、旧消费方忽略；默认（关）口径逐字不变，关闭即回平常 → TC-SQ-01/07。
- **缓存翻转以「键并入开关值」为准**：键＝`squads:all:${includeTrainee}`，翻转后旧键载荷不会被命中；最坏陈旧＝config 记忆化 ≤60s（`src/core/config.ts` isolate 级），记忆化一过期即换键重算；写路径代际 purge 可让换键提前发生，24h TTL 只是键不变时的兜底（原「靠写路径代际 purge 失效」口径已作废）→ TC-SQ-05/06。
- **回 enforce 前先收名单 + 训练营 XP 口径**：四键豁免不含 `trainee_size`/`trainee_growth` ⇒ B 批后回 enforce 时，69 名训练营球员的数量与可成长性必须自行过这两条，否则任何提交被 422 卡死，需先收名单（列入上线 runbook）；特例期训练营球员上场不记场次 XP（`src/worker/results.ts:651/665/670/685` 四类事件对 trainee `continue`），成长只走赛季结算固定 XP（`src/worker/growth.ts:305-330`，`trainee_season` 默认 40 / 半程 15，锚 `trainee:${season}` 幂等）⇒ 教练侧「踢了没收益」，若期望「上场就长」需另开改动（待拍）→ TC-BATCH-09。
- **生产写批顺序不可颠倒**：开关未先生效就写 69 人 `trainee`，赛事侧下个整点同步会从 tour 删人；回滚必须精确（按 season+club_id）且只回本批 69 人 → TC-BATCH-02/08。
- **豁免最小化**：四键只放宽四项（squad_min 19 / squad_max 32 / trainee_max 8 / growthPa87 7），无门将、不可成长训练营、缺合同、梯度仍照拦 → TC-BATCH-06。
