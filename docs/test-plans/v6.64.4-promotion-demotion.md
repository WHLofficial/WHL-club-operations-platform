# 测试计划 · v6.64.4 上调/下放机制（批次二）

## 背景与范围

正式合同 ↔ 训练营名单双向挂钩：下放（正式→训练营，即时转 5m/0.75m）、上调（训练营→一线队，谈正式合同）、练满自动开上调、解约冻结、自助取消、注册双向校验、`transfer_promotion` 闸位（零迁移默认行）。顺带收口 v6.64.3 缺口（match 成约未转 formal）。

**不改动**：匹配/激活/海捞既有链路；解约费公式；谈判成功率模型；直签训练营（trainee 签入）。

## 变异验证（最坏情况口径）

- M1 撤 match 分支 contract_type 写入 ⇒ TC-M1 红。
- M2 注册校验删 trainee_contract 或 first_team_contract 规则 ⇒ TC-R1/R2 红。
- M3 下放名额计数去掉 status='completed' 或窗口过滤 ⇒ TC-D2 红（跨窗/在途行误计）。
- M4 下放守卫去掉 pa−ca>0 ⇒ TC-D3 红。
- M5 匹配当窗例外去掉 ⇒ TC-D4 红。
- M6 附加费公式去掉或改 (F−15)×0.3 ⇒ 常数 ⇒ TC-P3 红。
- M7 关窗强约去掉无条件（挂回 config/force）⇒ TC-P5 红。
- M8 解约冻结去掉（回「审核才收费」）⇒ TC-T1 红（无 hold）。
- M9 取消不解冻 ⇒ TC-T3 红。
- M10 预约开会兜底删步 ⇒ TC-P7（闸关分支）红。
- M11 FIXED_FEE_TYPES 不加 promotion ⇒ submitReleaseFee 可改 F ⇒ TC-P8 组内 F 固定断言红。
- M12 chooseTrainee 拒绝名单漏 promotion ⇒ TC-P9 红。
