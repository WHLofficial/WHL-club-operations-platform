- ④ 对比页 2 人态热区图落点：两侧各一张、3 人态不出、吸顶条不出。

- ⑦ 徽章计数统一：`badgeCountItems`（金在前 + 零值抑制）、三密度 `icon / text / chip`、`BADGE_KIND_LABEL`，四个调用点（球员卡头 / 升级方案 / 提示句 / toast / 对比页 / 球员库卡片 / 表格 badges 列）。

- ⑪ 后端读路径缺陷：`/api/players/:id` 的 seaComps `signFee` 对 `fee ≤ 0` 的历史成交行不再抛 `RangeError`（500）。

**Out of scope**

- 跑动热图（真实位移数据）与任何新数据源：本轮热区图只表达「位置拓扑 + 主/副位」，不引入轨迹。
- 图表库（echarts 等）：共享件为手绘 SVG，禁止进包。
- 表格 ps 列的 webp 图标：compact 形态有意不拉图标（性能），图标字体 / sprite 属将来议题。
- 生产动作：push、部署、生产数据读写。本增量零迁移、零生产写（唯一后端改动是读路径护栏），全部用例本地执行。
- 全站徽章形态统一：密度差异（表格 text / 卡片 icon·chip）属场合差异，不做「同一形态」。

## 最坏情况口径（铁律）

- **空槽绝不归零**：`Number(null) === 0` 是本仓反复踩的坑（0 是合法 id：GK、槽位起点）。三处消费点必须一致——`positionName`（空槽 ≠ GK，否则热区图凭空给 GK 上主位绿、球员页多一枚 GK 芯片）、`psBadgesOf`（空槽 ≠ 槽 1，否则金判定整体前移）、`heatStateOf`（非法码不得当主位）→ TC-REF-01、TC-PSCOL-01、TC-HEAT-05/06、TC-CMP-ATTR-03。
- **无存档球员绝不画假图**：`game_attrs = null` 的长尾球员（生产 18,301 人中仅 570 有完整面）在老对比页实现下会画出「塌成圆心」的退化多边形，看起来像「六维全 0」而不是「没有数据」。共享件口径＝全空序列不画多边形与白点、环带与轴线照画 → TC-ARR-10、TC-CMP-DESK-01、TC-E2E-05F。**这是本轮有意行为变化，spec §7 已登记**，不得当 bug 回改。
- **计数语义单一出处**：金在前 + 零值抑制只准在 `badgeCountItems` 里写一遍；任何调用点自行拼字符串（原 `planBadgeText` 的银在前、对比页的无抑制）都是回归 → TC-BDG-01/02/03 + 各调用点用例。
- **共享件替换不得改既有形态**：`head` 变体承接球员页既有雷达（v6.19.0 起的 232×156 / R48 / 五档色 / 轴数值档色），几何、环带数、轴标、空值「—」必须逐项等价；对比页替换私有实现后，1/2/3 人与吸顶条的**结构性**断言（多边形条数、无文字 mini）必须仍在 → TC-ARR-01…07、TC-CMP-ATTR-01/02、TC-REG-05。
- **e2e 断言不得空转**：⑤f 改为数据驱动取样后，期望值由探针推得——最坏情况是「期望恒等于实际」（写错判据则断言永不红）。判据必须与后端口径一致（`PosID ≥ 0`；「有可上雷达的存档」＝存在非元数据正数属性值），且**不足 3 名有存档球员时必须 `console.warn` 备注降级**（本地只有 1 名）→ TC-E2E-05F。
- **类名连坐**：本仓有 v3.4.0 `.pos-chip` 覆盖他页的教训。本轮新增 `.heat-*` / `.radar-*` / `.badge-count*` / `.badge-chip*` / `.ps-badge-compact*`，并删除 `.cmp-radar-*` / `.cmp-heat*` / `.lib-card-chip*`——删的类若有 JSX 残留即样式悬空 → TC-REG-05。
- **jsdom 只锁语义不锁视觉**：jsdom 不跑样式表。配色、环带透明度、块缝、断点堆叠只能锁类名 / 几何属性 / 内联属性，真实视觉由 e2e 三视口扫描与真机目测兜底 → TC-PHM-03/05、TC-ARR-02/08/09、TC-REG-04。
- **数据面最坏**：本地 D1 夹具 30 名球员里只有 1 名（999999 阿七，ST，`{"PosID1":25,"PosID2":23,"PSID1":1,"PSID13":102,"finishing":88,"PA":90}`）带可上雷达的存档；99001 / 99002 是 71 键骨架但值全 `null`；9001–9006 无存档；`PosID = -1` 是源表占位（≠「有位置数据」）→ 相关用例按「本地实测形态」回填，生产形态留待上线后只读抽查。

## 用例

编号前缀：`HEAT`＝热区图纯函数与拓扑；`PHM`＝热区图共享组件；`RAD`＝雷达纯函数；`ARR`＝雷达共享件四变体；`CMP-ATTR`＝球员页属性页签头部；`CMP-DESK`＝对比页桌面形态（沿用 v6.34.0 编号）；`CMP-POS`＝对比页位置·徽章行（沿用）；`REF`＝位置名护栏；`BDG`＝徽章计数；`PSB`＝PlayStyle 徽标；`PSCOL`＝表格 ps / badges 列；`COMPS`＝后端成交参照（沿用）；`E2E`＝e2e 场景专项；`REG`＝回归。每条标注可覆盖层：`vitest 纯函数` / `vitest 组件` / `e2e` / `手工`。

### TC-HEAT · 热区图纯函数与拓扑（①）

**TC-HEAT-01 · 12 个位置码与球员库 POSITIONS 同集合**（P0 · vitest 纯函数）
- 前置：`web/src/lib/heatmap.ts` 的 `HEAT_CODES`。
- 步骤：与球员库筛选用的 `POSITIONS` 集合对拍。
- 预期：同集合（不多不少）；顺序即渲染序（GK 起、ST/LW 收）。
- 变异：码表新增/漏一项（如把 `CAM` 写成 `CM2`）→ 本条红。

**TC-HEAT-02 · 12 块几何完整性与不重叠**（P0 · vitest 纯函数）
- 步骤：遍历 `HEAT_SLOTS`。
- 预期：12 块全在场且 code 唯一；每块落在 `HEAT_VIEW`（245×200）内；块两两不重叠（含 GK 块）。
- 变异：块坐标手写错值（越界 / 重叠）→ 本条红。

**TC-HEAT-03 · 网格度量：列宽 / 列缝 / 行缝 / 跨块 / GK 块**（P1 · vitest 纯函数）
- 步骤：读三列 x 与宽、同列纵向缝隙、中列五等分高度、左右列前卫与边后卫高度、GK 块尺寸与居中。
- 预期：三列各 75 宽、列缝 5；同列块纵向缝隙均为 5；中列五等分 27；左右边前卫 / 边后卫跨两块 59；GK 块 69×26 居中于底部梯形带（`HEAT_GK_BAND = '4,164 241,164 204,196 41,196'`）之上。
- 备注：块高差是拓扑示意（本仓化，非 sofifa 等比）；数值改动须同时改本用例与 spec §1.1。
- 变异：块缝改 4/6、中列改四等分 → 本条红。

**TC-HEAT-04 · `heatPositionsOf`：清非法 + 去重 + 保序**（P0 · vitest 纯函数）
- 步骤：输入含 12 码外的值、重复码、空数组。
- 预期：过滤码表外的值并去重、保留输入顺序；空输入返回空数组。
- 变异：不去重（重复码占副位）/ 改用 Set 丢顺序 → 本条与 HEAT-05 红。

**TC-HEAT-05 · `heatStateOf` 三态矩阵**（P0 · vitest 纯函数）
- 步骤：空位置码 / 单码 / 多码（首码主位其余副位）/ 重复码 / 码表外的值 / 超过 3 个位置码。
- 预期：空 ⇒ 全 `none`；首码 `main`、其余 `sub`；单码只一块 `main`；重复码去重后不占副位；码表外的值一律忽略（不成为主位）；超过 3 个位置码时全铺副位（第 4 起也是 `sub`，不丢）。
- 变异：非法码当主位 / 副位上限截断丢码 → 本条红。

**TC-HEAT-06 · `heatStateOf` 门将特例**（P0 · vitest 纯函数）
- 步骤：纯门将（`isGk` 且只有 GK 码）/ 兼场门将（GK + 外场码）/ GK 不在首码 / 非门将标志但码是 GK / 门将标志但码为空。
- 预期：纯门将只 GK 块主位绿、其余淡显；兼场门将 GK 主位、兼位副位；GK 不在首码时照常按序铺绿（不特殊对待）；非门将标志但位置码是 GK 时照常铺绿；门将标志但位置码为空时全淡显。
- 变异：判据写成「任一 GK 即纯门将」→ 兼场门将用例红。

**TC-HEAT-07 · `heatToneClass` 三态类名**（P1 · vitest 纯函数）
- 预期：`main → heat-main`、`sub → heat-sub`、`none → heat-off`（CSS 三色：`#2b8a3e` 白字 / `#66a80f` 白字 / `#faf6ef` opacity .55 字 `#c3b294`）。
- 变异：主/副互换 → 本条与 TC-PHM-03 红。

### TC-CMP-ATTR · 球员页属性页签头部（③⑥⑩）

**TC-CMP-ATTR-03 · 空位置数据：热区图不渲染 + 头部回退两列 + 雷达照常**（P0 · vitest 组件）

- 变异：去掉空态判据（`null` 经 `Number()` 归 0 ⇒ 出 GK 主位）→ 本条红（这是本轮修掉的 `positionName` 缺陷的回归位）。

**TC-CMP-ATTR-04 · 纯门将：只 GK 块主位 + 雷达换 GK 六轴**（P1 · vitest 组件）

- 预期：热区图只 GK 块 `heat-main`、其余 11 块 `heat-off`；雷达轴换 `['DIV','HAN','KIC','REF','POS','SPD']`。
- 变异：门将仍出外场六轴 / 纯门将给外场块上色 → 本条红。
