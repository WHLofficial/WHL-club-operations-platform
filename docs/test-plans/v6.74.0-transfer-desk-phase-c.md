| TC-BE-05 | 同一挂牌 55 笔出价 | GET panel | `bids` 恰 50 条、`id DESC` | P1 |

## 3. 缓存与失效

| 编号 | 前置 | 步骤 | 预期 | 优先级 |
|---|---|---|---|---|
| TC-Q-01 | 浮层打开 | 30s 内重复聚焦 | 不发第二次请求（staleTime 30s） | P1 |
| TC-Q-02 | 浮层内出价成功 | 操作后 | invalidate 当前 `listing` 与 `['market','transfer-panel']`，状态条/出价历史即时刷新 | P0 |
| TC-Q-03 | 报价动作或谈判动作 | 操作后 | `useOffersInvalidation` 同时失效 transfer-panel | P1 |
| TC-Q-04 | `playerId` 非正整数 | 渲染浮层 | 不发请求（enabled=false） | P1 |

## 5. 最坏情况口径与变异验证

- 最坏数据：同球员多张历史挂牌、50+ 笔出价、in/out 同时有 pending、active+settled 双会话、未绑队。
- 变异验证（逐条临时改坏、确认恰好命中对应用例后恢复）：
  1. 选单条件删掉 `pending_review` → TC-BE-02 红；
  2. `myBids` 改成跟当前 listing → TC-BE-06 红；
  3. offers 合成一条查询 → TC-BE-07 红；
  4. transfer 去掉 `to_club_id IS NOT NULL` → TC-BE-11 红；
  5. 已结束文案退回「输给」→ TC-UI-05/06 红；
  6. 浮层点报价不先 `onClose` → TC-UI-11 红。
