## 范围

**In**：档位校准（recalibrateTierStatements）、两信号演化（satisfactionDelta / windowWinRate / evolveSatisfactionForClub）、品牌主动解约、签约档位名额守卫（tierQuotaOf / signNaming）、冠军加成（leagueStandings / championBonusStatements / settleSeason 集成）、buff 生效点（activityIncome attendBuff / evolveFans fansBuff）、config 三键 + champion 键。
**Out**：C3 招商轮（offer_spawn 仍播报）、事件信号参与演化（Q2 裁决不做）、管理端/教练端 UI 视觉细节（e2e 冒烟只验可达与不炸）。

## 最坏情况口径（铁律）

- 全池热度 < 1.0 → 头部**空缺**（不注水）。
- 无主场比赛 / 无有效赛果 → 信号中性 0，不借中性上座率 1.0 白拿 +1。
- 同窗重复关窗 / 赛季重放 → 幂等，不重复演化、不重复加成。
- 跨队并发签约 → INSERT 内原子 COUNT 守卫，不超卖。
- 冠军是 CPU 队 / 无 AUTH 映射 / 无冠名 → note 跳过不炸批。
