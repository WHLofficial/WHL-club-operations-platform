# v6.40.0 · 站内信徽章 / 跳转 / 窄屏收口（测试计划）

- **范围**：30 个通知模板各配中文徽章（配色沿八类类目色）+ 类目页签与「本类全部已读」+ 行整行跳转（ref 精确 / 类目固定落点两级）+「见过即已读」（视口内即标）+ 收件篮窄屏两行卡片；端点半点：列表 item 增 `clubId`/`ref`、`?category=` 筛选、`?by=category` 未读计数、`read{all,category}`；目标页 `?offer=`/`?order=` 播种 + 命中高亮。
- **缘起**：用户 m03242「脑暴下一个功能，给所有类型的站内信分配徽章，并实现跳转功能，以及窄屏显示优化」；四条拍板（m03254 答）：① 徽章模板一一对应但配色切成八类；② 跳转「类目落点 + 有据时精确」；③ 整行跳转，已读改「见过即已读」；④ 窄屏重点是页签筛选 / 徽章与时间重排 / 未读置顶与日期分组 / 两行卡片加高点击区，且页签与未读置顶桌面端同样生效。
- **判级**：minor（两处用户可见新能力：跳转 + 徽章/页签；一条既有语义变更：已读改见过即已读）。
- **零迁移**：`notifications.payload` 本就是 TEXT，`{text}` → `{text, ref?}` 属载荷扩展；老行无 ref 走类目落点。索引是否需补（迁移 0066）由 L6 读量探针裁决，本版默认不加。
- **不在范围**：TopBar 未读红点（只有点无数字，不动）；`?listing=` 激活页精确落点（激活页列表实体是球员、无工单/挂单实体，改跳 `/players/<id>`）；`event_*` / `naming_*` 的实体参数（**刻意不存 ref**：这两类无可用实体页）；QQ/FEISHU 渠道文案；推送/邮件。

## 一、不变量

1. **模板 ↔ 徽章一一对应**：`src/worker/notify.ts` 里 `renderNotification` 的每个 `case '模板'` 字面量都必须在 `NOTIFY_META` 有且只有一个条目；反向也成立（集合双向相等，30 条）。label 非空、唯一、≤6 字（徽章 + `title` 挂原始模板名）。
2. **配色只有八类**：`categoryOf(template)` 恒返 8 个类目之一；类目 ↔ 既有 `.badge` 修饰色一一绑定（赛果 green / 成长 gold / 报价 blue / 激活 sky / 事件 orange / 命名 purple / 商城 red / 窗口 gray）。未知模板 ⇒ `categoryOf` 返 `null`，前端退化为无修饰色徽章 + 原始模板名 + **不可点**（宁缺勿错）。
3. **ref 只存 UI 今天真能用的三型**：`offer` / `player` / `shop_order`；`notificationRefOf` 按 `data` 里的 `offerId` / `playerId` / `orderId` 抽取，缺字段或该模板无实体 ⇒ `null`。老 payload（无 ref）⇒ item `ref = null`，前端走类目落点。
4. **跳转优先级固定**：ref 精确 → 类目固定落点 → `null`（行不可点）。需要 `clubId` 而该行没有 ⇒ `null`（不可点，绝不猜）。ref 落点：`offer` → `/market/desk?tab=offers&box=…&offer=<id>`（议价四个模板 → `?tab=nego`；撤回/过期/自动拒绝 → `box=out`）；`player` → `/players/<id>`；`shop_order` → `/shop?order=<id>`。
5. **已读语义 = 见过即已读**：行进入视口（IntersectionObserver，预读余量约 120px）即批量 `POST /api/notifications/read {ids}`；无 IntersectionObserver 的环境（jsdom / 老浏览器）退化为「渲染即标记」。**标已读不回改本页视觉**：置顶与否按本次加载时的服务端 `readAt` 判定，避免刚滚过就跳位闪烁。
6. **列表契约向后兼容**：item 恒有 `clubId`（可为 `null`）与 `ref`（老行为 `null`）；`?category=` 只改 WHERE 与 unread 计数口径，`nextCursor` 语义不变（满页且有第 31 行才给游标）；`read{all:true, category}` 只清本类。
7. **两端同结构**：类目页签与未读置顶/日期分组在桌面与窄屏都生效；窄屏（≤640）为两行卡片（第 1 行徽章 + 时间右对齐，第 2 行正文满宽），行点击区 ≥ 44px，页签 `.seg` 单行横滑。
