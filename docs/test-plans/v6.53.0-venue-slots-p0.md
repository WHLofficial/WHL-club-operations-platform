## 5. 风险与最坏情况口径

| 风险 / 场景 | 概率 | 影响 | 缓解与验证 |
| --- | --- | --- | --- |
| 生产已有 ≥2 个 `status='open'` 行 ⇒ 0078 第 1 条唯一索引失败 | L | apply 占用一次生产窗口 | apply 前跑 `SELECT COUNT(*) … status='open'`；>1 先人工关窗；单测锁「两 open 行 ⇒ 第 1 条失败、四列一列未加」 |
| 生产 `config` 已显式写 `activity_slots='2'` / 旧 `activity_config` ⇒ 新默认不生效 | M | Plan A 静默失效、旧经济继续跑 | 迁移不覆盖运营配置；apply 前只读回读两键；`legacy_range` 保留旧经济并给 `configWarning` |
| 事件预置（K=0, mod≠1）与活动同窗：活动效果被事件「一场即清」吞掉 | M | 玩家看到乘数只作用 1 场 | `CASE WHEN attendance_mod_matches=0 AND next_attendance_mod<>1 THEN 0`；页脚注「与一次性事件叠加时以事件为准」；单测锁 `mod=1.425 / K=0` |
| 企业日声望 ≥20 需 2–3 季累积 | H | 试点窗可能无人能排企业日 | 保持门槛；文案注明「企业日需累积声望」；观察采纳率不作硬门槛 |
| 设施全 0 ⇒ 只剩演唱会/开放日 | M | 采纳率低 | 保持锁定（P0 要验证门槛）；是否发升级券属运营决策 |
| 预览按 `expectedDamage`、关窗按实际掷点 ⇒ 两口径有差 | H | 玩家投诉「推荐值与实收不符」 | 卡面写「预期」；`VenueQuote` 同时返回 `damage/expectedDamage`，不混用；单测分列两口径 |
| 开窗失败但经纪人已重掷 | H | 窗没开、球员档位却变了 | 重掷并入 `openBatch`；`CREATE TRIGGER … RAISE(ABORT)` 测回滚后 `players.agent_tier` 逐行不变 |
| `consumption` 改锚后商城/冠名/档期一起进窗 | M | 运营误以为只影响档期 | 设计明确要求；管理端可临时改回双 none；R12 风险登记 |
| `venue_policy` / `city` 无消费方 | L | 无用列 | `venue_policy` 供方针卡；`city` 纯预留，删除只需一行 DDL |
| `activity_slots=0` 被误当成「默认 2」 | M | 关闭档期失效 | `slotsForCapacity` 首句 `if (slotCap <= 0) return 0`；单测 `(12000,0)=0` |
| 迁移重跑 `ALTER TABLE` 报 `duplicate column name` | H | 本地重放失败 | 幂等靠 `d1_migrations` 账本；索引/表 `IF NOT EXISTS`；单测空库与存量各一次 |
