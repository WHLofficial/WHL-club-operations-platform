# 测试计划 · v6.24.0 转会市场改版（三入口统一竞价 + 卡片浮层改版）

- 设计：qa-test-planner（2026-10-03）。执行层：vitest + 变异验证 + e2e + 手动抽验。
- spec：`docs/superpowers/specs/2026-10-03-transfer-market-revamp-design.md`；计划：记忆 `plan-v6.24.0-market-revamp.md`。
- 基线：vitest 69 文件 / 1228 例、e2e 19/19（v6.23.0 收口值）。迁移 0058 → 新增 0059。

## 1. 范围

**In**：三入口统一竞价（激活首价窗→bidding）、匹配窗基准改最终最高价、挂牌即落 deadline_at、listed 提前收口、整数出价、归零即拒三层、卡片 rail 骨架 + 浮层/抽屉 + 读秒倒计时、转会台 tab 三更名删挂牌表单、海捞激活分离、暗黑模式文字修复、375px 防折行。
**Out**：报价域金额（不整数化）、bidDeadline 引擎数学（不改，只补调用）、球员页 SideOps 挂牌入口、管理端审核流程。

## 4. 风险与最坏情况

- **触发器重建**：0059 DROP+CREATE 失败会留无守卫状态——apply 后必须只读核验触发器 SQL 与 0059 文件逐字一致。
- **listed 提前收口**：最坏情形 = 挂牌即被误下架（deadline 首算错）——TC-A03/A08 成对验证「落库值正确」+「到期才收口」。
- **激活状态机**：最坏情形 = 首价窗竞态（settle void 与出价并发）——TC-A06 用触发器层直插验证，不依赖预检。
- **倒计时**：最坏情形 = 系统校时回拨显示错乱（TC-B02）+ 长列表 N 卡片各起 interval 造成性能塌方（单例 tick 结构性排除，TC-B01 停表断言）。
- **存量兼容**：TC-A12 锁 NULL 回落实时算路径不被顺手删掉。
