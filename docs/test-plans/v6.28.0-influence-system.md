## 0. 落地口径与计划偏差点（以本节为准）

计划文件 `memory/plan-v6.28.0-influence-system.md` 与实现已落口径的差异（逐条留痕）：

| 计划口径 | 落地口径 | 依据 / 理由 |
|---|---|---|
| 「零迁移」 | **新增 `src/db/migrations/0062_stadiums_fans_window_start.sql`**（对计划的有意偏离） | 每场演化即时改写 `stadiums.fans` 后关窗批无法反推窗初值，而对赌奖金的「本窗死忠增长率」需要窗初；本仓没有计划里假设的 `window_fans_log` 表。`tests/d1.ts` 的 `MIGRATION_FILES` 已追加 0062 |

## 1. 范围

**In**：① A 段影响力公式 `(队壳 shell_influence + 阵容 playerSum) × 级别系数 + 奖励分 bonus_points`——`teamInfluence(stadium, playerSum, tierCoef)` 第三参必填；config 新键 `influence_tier_coefs`（默认 `{"premier":1.2,"second":1.0}`）；未登记/未定级/派生失败一律 **1.0**；级别真源 `deriveClubTier`/`deriveClubLeagues`（`src/worker/tier.ts`）；消费点全链路：上座 demand 的主/客队影响力（`src/worker/home.ts` 上座钩子内）、关窗批 `diehardTarget` 入参、主场档案展示（`src/worker/routes/clubs.ts`）、管理端俱乐部详情、CPU 接管向导 `cpu-convert` 预览与 `seed-ops` 写入（两者必须同一套系数）。级别档位系数（`attendance_model.tier_table.attend_coef`）与上座其余因子不变。② B 段死忠每场演化：赛果确认钩子④与 `match_attendance` 上座/收入**同一批 SQL 原子**；per-match 系数 config 键；入参单场满座率 `attendance/capacity`、近 3 场战绩分、青训等级、冠名档位 `fansBuff`；不消费 `fan_mood`；关窗批**本窗有主场场次的队不再演化**（防双记账，只推进快照），无主场场次的队按窗系数兜底一次（中性满座率 1.0）；`fan_mood` 对所有队按窗一次（演化之后）；`summary.fansClubs` 仍只统计死忠变化 ≥0.5 的队数；迁移 0062 与 `fans_window_start` 快照语义、对赌 `fansGrowth`。③ C 段数据批脚本 `scripts/prod-<日期>-influence-recalc/`（只交付、不执行，等用户单独授权）：16 支人类队图值导入、死忠目标重算、历史链式重演（含随机项取中点）、`match_attendance` 重写、收入重记替换 + `balance_after` 全链重放、守恒断言、可重跑/失败可恢复。④ D 段管理端侧栏四域分组（12 项归 4 组 + 总览单独，路由不变；「消费」文案改「消费工单」，URL/文件名不变；375 宽抽屉不回归）。⑤ E 段总览补卡：「待审消费工单」「待选事件」2 张计数卡（计数卡 **6 → 8**，任务书写的「5 → 7」少算 v6.27.0 的 CPU 队卡）；「待审消费工单」= `shop_orders.status='pending'`（与 `AdminShopPage` 默认筛选同 WHERE 片段）；「待选事件」= `event_occurrences.status='pending' AND event_type='choice'`（与教练端待选列表同口径，**即发型残留 pending 行不算**；不按赛季过滤）。

**Out**：A/B 段之外的公式口径改动（`attend_coef`/上座其余因子不动）；`fan_mood` 语义改动；D 段不新增/删除导航项、不复用旧路由；E 段不做新统计口径（只补两张卡）；C 段**本版不执行**（生产写、迁移 apply、任何 prod 查询都不在本计划执行范围内）；不做对赌奖金历史追溯、不动 CPU 队历史（无账本无上座快照）、不涉及赔率/竞猜侧。

**Entry**：A/B/D/E 代码与测试就绪；测试库跑完全部迁移（含 0062，`tests/d1.ts` 清单已含）；D/E 前端可构建。**Exit**：`npm run typecheck` 三份 tsconfig 零错；`npx vitest run` 全绿（≥78 文件 / 用例数 ≥1339，D/E 用例加完再上调）；`npm run build` 过；`npm run dev`（wrangler dev --port 8791）+ `npm run test:e2e` **21/21**（⑫ 375×812 全路由零溢出扫描、⑬ 管理端抽屉）；变异 M1–M15 按预期红后还原全绿。C 段：脚本 dry-run 差异报告 + 守恒断言在测试夹具上全过（**生产执行另等授权**）。
